# 프로젝트와 기능

## 프로젝트 목적

Potato Land는 중고거래와 24시간 경매를 제공하는 지역 기반 거래 서비스다. 인증, 상품, 경매, 채팅, 알림, 거래, 후기, 마이페이지, 관리자 기능을 하나의 서비스 흐름으로 연결한다.

## 사용자 역할

| 역할 | 주요 권한 |
|---|---|
| 비회원 | 메인·상품·경매·공개 프로필·공개 후기 조회 |
| 회원 | 상품 등록, 입찰, 관심상품, 채팅, 거래, 후기, 계정 관리 |
| 관리자 | 회원 정지, 상품 삭제, 낙찰 내역과 운영 통계 조회 |

## 핵심 기능

- 전화번호 인증 기반 회원가입·아이디 찾기·비밀번호 재설정
- HttpOnly cookie 기반 Access/Refresh Token 인증과 Redis session rotation
- 중고상품 등록·검색·수정·삭제·관심상품
- 24시간 경매 등록·동시 입찰·종료 복구·낙찰 거래 생성
- Socket.IO 채팅·알림·경매 실시간 갱신
- 거래 완료·취소와 1~10점 후기
- 개인 활동 내역과 관리자 운영 대시보드

## 확정 정책

- 경매 입찰 원본은 모두 보존하고, 순위 화면에는 사용자별 최고 입찰만 표시한다.
- 진행 중 경매에는 판매자 개인 채팅을 만들지 않는다.
- 경매 종료 시 판매자와 최고 낙찰자의 채팅방을 자동 생성하거나 기존 방을 재사용한다.
- 경매 삭제는 모든 입찰자에게 DB 알림을 저장한 뒤 온라인 사용자에게 Socket으로도 전송한다.
- 후기 태그 기능은 제거하고 평점과 선택 내용만 저장한다.
