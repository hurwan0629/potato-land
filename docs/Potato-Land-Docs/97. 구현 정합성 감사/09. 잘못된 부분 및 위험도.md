# 잘못된 부분 및 위험도

## P0 - 즉시 차단해야 하는 문제

### 1. SMS 인증번호 평문 로그

- [`backend/src/modules/auth/auth.service.js`](https://github.com/hurwan0629/potato-land/blob/061e78c2bcd039191277b211a51fd08bb1669feb/backend/src/modules/auth/auth.service.js) · `sendPhoneVerification`
- [`backend/src/server.js`](https://github.com/hurwan0629/potato-land/blob/061e78c2bcd039191277b211a51fd08bb1669feb/backend/src/server.js) · `configureSmsProvider`

인증번호, 전화번호, purpose 또는 전체 SMS 본문이 로그에 남는다. 로그 접근자는 계정 인증을 우회할 수 있다.

**수정 방향:** code/text/payload 로깅 삭제. 개발에서는 마지막 2자리만 표시하거나 테스트 provider가 메모리로 결과를 반환하도록 분리.

### 2. 관리자 라우터에 인증·role guard 없음

[`backend/src/modules/admin/admin.router.js`](https://github.com/hurwan0629/potato-land/blob/061e78c2bcd039191277b211a51fd08bb1669feb/backend/src/modules/admin/admin.router.js)

현재 controller는 501이지만 구현이 들어오는 순간 공개 관리자 API가 된다.

### 3. 인증 미들웨어 이중화

- JWT-only: [`backend/src/common/middlewares/auth.middleware.js`](https://github.com/hurwan0629/potato-land/blob/061e78c2bcd039191277b211a51fd08bb1669feb/backend/src/common/middlewares/auth.middleware.js)
- DB-validating: [`backend/src/common/auth/accessToken.js`](https://github.com/hurwan0629/potato-land/blob/061e78c2bcd039191277b211a51fd08bb1669feb/backend/src/common/auth/accessToken.js)

같은 token인데 도메인에 따라 탈퇴·정지 사용자의 접근 결과가 달라질 수 있다. 문서는 모든 보호 API가 현재 DB 상태를 확인하도록 요구한다.

## P1 - 핵심 기능 차단

### 4. 35/68 URL 미실행

메인 2, 중고 7, 사용자 2, 경매 4, 후기 3, 마이페이지 5, 관리자 12.

### 5. 업로드 URL prefix 불일치

- 생성: `/resources/...`
- 제공: `/uploads`

채팅 이미지와 경매 이미지가 저장돼도 브라우저 접근이 실패한다.

### 6. 실시간 경매 핵심 미구현

입찰 HTTP, 입찰 목록, favorite, auction Socket join/leave, winner/transaction/notification, recovery start가 없다.

### 7. 경매 종료가 상태 변경만 수행

[`backend/src/modules/auctions/auctions.repository.js`](https://github.com/hurwan0629/potato-land/blob/061e78c2bcd039191277b211a51fd08bb1669feb/backend/src/modules/auctions/auctions.repository.js) · `finishAuction`

문서가 요구한 낙찰 결정·winning bid·거래·채팅·알림이 없다.

### 8. 회원 탈퇴 연쇄 정리 누락

게시글, 경매, 입찰, 진행 거래, 알림, timer, 상대방 Socket 전파가 없다.

### 9. 후기 계약이 DB부터 없음

태그 route, 태그 table, review-tag relation, 작성/조회 service가 없다.

## P2 - 높은 정합성·유지보수 위험

### 10. request/response DTO drift

- `verificationToken` ↔ `editToken`
- `newPassword` ↔ `password`
- 경매 personal fields 고정값
- transaction detail 집계 누락

### 11. router guard 누락

`used`, `mypage`, `reviews`, `admin`은 라우터 수준 인증이 없다.

### 12. migration 체계 중복

실제 `backend/database`와 stale 가능성이 높은 `backend/src/database`가 동시에 존재한다.

### 13. 거래 controller 비대화

정책, SQL, transaction, DTO, Socket, notification이 한 파일에 집중돼 변경 시 회귀 위험이 높다.

### 14. 테스트 공백

68개 URL, Socket, Redis session, 경매 동시 입찰, 탈퇴/관리자 연쇄 정리를 검증하는 integration test가 없다.

### 15. 빈 운영 파일

`compose.deploy.yml`, `compose.test.yml`이 0 byte다.
