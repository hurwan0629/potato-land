## 정합성이 좋은 부분

- 문서의 주요 enum과 13개 핵심 테이블을 대체로 반영
- 거래의 active/completed partial unique index
- chat client_message_id unique
- rating 1~10
- read_at 보완 migration
- category seed 및 migration runner 존재

## 문제

1. 후기 태그 테이블과 review-tag relation이 없어 문서의 tag API를 구현할 수 없다.
2. migration 체계가 두 군데 존재한다.
   - `backend/database/migrate.js` + `backend/database/migrations`
   - `backend/src/database/migrate.js` + `backend/src/database/migrations/001_create_users.sql`
3. 실행 스크립트는 첫 번째 경로를 쓰므로 두 번째는 stale schema가 될 가능성이 높다.
4. 테스트/배포 compose가 빈 파일이라 로컬과 CI/배포 재현 경로가 분리돼 있다.
5. 실제 운영 데이터에서 migration 적용 여부는 정적 검사로 확인하지 못했다.
