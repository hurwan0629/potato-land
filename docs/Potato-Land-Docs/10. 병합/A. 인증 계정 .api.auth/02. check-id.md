1. router
```
authRouter.get("/check-id", checkLoginId);
```
- 미들웨어는 없음

2. controller
```
export const checkLoginId = asyncHandler(async (req, res) => res.status(200).json({ success: true, data: await checkLoginIdAvailability(req.query.loginId) }));
```
- 쿼리스트링에 존재하는 `loginId`값을 전달하게됨

3. service
```
export async function checkLoginIdAvailability(rawLoginId) {

  const loginId = validateLoginId(rawLoginId);

  return { loginId, available: !await findUserByLoginId(loginId) };

}
```
- 패턴을 먼저 확인한 후
- 데이터베이스에 해당 아이디가 존재하는지 확인하게 된다.

> 이것도 큰 문제는 없어보인다

> 아이디 선점같은게 없어서 회원가입하는 순간에 아이디가 막힐 수 있지만 일단 지금은 큰 문제가 없을 것 같다.
