# 이전 문서 보관소

이 폴더의 문서는 설계 변경 과정과 과거 의사결정을 보존하기 위한 자료다.
현재 구현을 처음 확인할 때는 상위 [`docs/README.md`](../README.md)부터 읽는다.

현재 정본의 소유 위치는 다음과 같다.

- 기능·정책: `docs/01. 프로젝트와 기능`
- 아키텍처: `docs/02. 아키텍처`
- 상태·DB·Redis·Socket room: `docs/03. 도메인과 데이터`
- HTTP·Socket 계약: `docs/04. API와 Socket`
- DB transaction·Redis·Timer·알림 실행 순서: `docs/05. 실행 흐름`
- 다이어그램: `docs/06. 다이어그램`
- Figma·CSS: `docs/07. UI와 Figma`
- 실행·테스트·로깅: `docs/08. 테스트와 운영`

과거 문서와 새 정본이 충돌하면 새 정본과 실제 코드를 우선한다.
