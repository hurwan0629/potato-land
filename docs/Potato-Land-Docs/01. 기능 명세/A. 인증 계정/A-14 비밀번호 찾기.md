# A-14 비밀번호 찾기

## 목적

사용자가 전화번호 인증 후 비밀번호를 재설정할 수 있게 한다.

## 정상 플로우

1. 사용자가 아이디와 전화번호를 입력한다.
2. 전화번호 인증을 완료한다.
3. 서버는 비밀번호 재설정 권한을 확인한다.
4. 사용자는 새 비밀번호를 입력한다.
5. 서버는 비밀번호를 hash로 저장한다.

## 예외

- 가입 정보 불일치
- 인증번호 만료
- 비밀번호 규칙 불충족
- 정지/탈퇴 사용자
