# A-09 정지 사용자 접근 제어

## 목적

관리자에게 영구정지된 사용자가 서비스를 사용할 수 없게 한다.

## 기준

- `users.banned_at IS NOT NULL`이면 정지 사용자이다.
- MVP에서 `banned_until`은 사용하지 않는다.

## 차단 범위

- 로그인
- 토큰 재발급
- 글 작성
- 입찰
- 채팅
- 거래 요청
- 관심 등록
- 송금 요청

## 일반 사용자 화면 표시

- 정지 사용자는 `삭제된 사용자`로 표시한다.
- 프로필 이미지와 프로필 이동은 비활성화한다.
- 기존 완료 거래와 후기는 보존하고 공개한다.
- 기존 채팅방과 메시지는 보존하되 읽기 전용으로 유지한다.

## 영구정지 후속 처리

1. 모든 refresh session을 삭제한다.
2. Socket 연결을 강제 종료한다.
3. 참여 중인 `REQUESTED` 거래를 `CANCELED`로 변경한다.
4. 소유한 진행 중 경매를 soft delete한다.
5. 최고 입찰자인 진행 중 경매의 최고 입찰자를 재계산한다.
6. Redis 경매 상태와 Timer를 정리한다.
7. 필요한 알림과 Socket 이벤트를 전송한다.
