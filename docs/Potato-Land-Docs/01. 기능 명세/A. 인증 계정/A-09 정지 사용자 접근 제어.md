# A-09 정지 사용자 접근 제어

## 목적

관리자에게 영구정지된 사용자가 서비스를 사용할 수 없게 한다.

## 기준

- `users.banned_at IS NOT NULL`이면 정지 사용자이다.
- MVP에서 `banned_until`은 사용하지 않는다.

## 차단 범위

- 로그인
- 토큰 재발급
- 글 작성
- 입찰
- 채팅
- 거래 요청

## 체크리스트

- [x] 로그인 시 정지 확인
- [x] refresh 시 정지 확인
- [x] 보호 API middleware에서 정지 확인
- [x] Socket 연결 시 정지 확인
