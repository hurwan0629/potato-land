# A-07 로그아웃

## 목적

사용자의 인증 상태를 종료한다.

## 정상 플로우

1. 사용자가 `POST /api/auth/refresh/logout`으로 로그아웃을 요청한다.
2. 서버는 refresh token을 확인한다.
3. Redis refresh key를 삭제한다.
4. access/refresh cookie를 만료시킨다.
5. 프론트는 비로그인 상태로 전환한다.

## 체크리스트

- [x] Redis refresh key 삭제
- [x] access cookie Max-Age 0
- [x] refresh cookie Max-Age 0
- [x] refresh cookie Path와 logout 경로 일치
- [x] 프론트 로그인 상태 초기화
