# A-06 로그인

## 목적

가입한 사용자가 계정으로 로그인하고 인증 쿠키를 발급받는다.

## 정상 플로우

1. 사용자가 아이디와 비밀번호를 입력한다.
2. 서버는 사용자를 조회한다.
3. 비밀번호 hash를 검증한다.
4. 탈퇴/정지 상태를 확인한다.
5. access token 15분, refresh token 7일 쿠키를 발급한다.
6. Redis에 refresh key를 7일 TTL로 저장한다.

## 예외

- 아이디 없음
- 비밀번호 불일치
- 탈퇴 사용자
- 영구정지 사용자

## 체크리스트

- [x] 정지/탈퇴 차단

- [x] Redis refresh key 저장
