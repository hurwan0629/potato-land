# A-10 회원 탈퇴

## 목적

사용자가 직접 계정을 탈퇴할 수 있게 한다.

## 정책

- 실제 삭제 대신 `users.deleted_at`을 저장한다.
- 탈퇴 사용자는 로그인과 토큰 재발급이 차단된다.
- 탈퇴 사용자는 Socket 연결과 보호 API 접근이 차단된다.
- 일반 사용자 화면에서는 `삭제된 사용자`로 표시한다.
- 프로필 이미지와 프로필 이동은 비활성화한다.
- 기존 완료 거래, 후기, 채팅 기록은 보존한다.
- 기존 채팅방은 읽기 전용으로 유지한다.
- 탈퇴 후 같은 login_id, phone, email은 재사용할 수 없다.

## 비활성화 공통 처리

회원 탈퇴는 관리자 영구정지와 같은 비활성화 서비스를 사용한다.

1. 모든 refresh session을 삭제한다.
2. Socket 연결을 강제 종료한다.
3. 참여 중인 `REQUESTED` 거래를 `CANCELED`로 변경하고 활성 상대방에게만 일반 취소 알림을 보낸다. 해당 거래가 없으면 알림도 없다.
4. 소유한 판매 중 중고글과 진행 중 경매를 soft delete하고 favorites를 제거한다.
5. 최고 입찰자인 진행 중 경매의 최고 입찰자를 재계산한다.
6. 관련 Redis 상태를 정리한다.
7. 관련 경매 Timer를 제거한다.
8. 필요한 알림과 Socket 이벤트를 전송한다.
