# A-11 프로필 및 회원 정보 수정

## 목적

사용자가 자신의 공개 프로필과 민감 회원 정보를 구분해 수정할 수 있게 한다.

## 구분

### 프로필 수정

프로필 수정은 마이페이지에서 바로 접근할 수 있다.

- 프로필 이미지
- 소개글 또는 상태 메시지

### 회원 정보 수정

회원 정보 수정은 현재 비밀번호 확인 후 접근할 수 있다.

- 닉네임
- 이메일
- 비밀번호
- 전화번호

## 처리 규칙

- 회원 정보 수정 진입 전 현재 비밀번호를 검증한다.
- 닉네임 변경은 중복 확인을 수행한다.
- 이메일 변경은 형식과 중복 확인을 수행한다.
- 전화번호 변경은 `CHANGE_PHONE` purpose의 전화번호 인증을 완료해야 한다.
- 비밀번호 변경은 새 비밀번호와 새 비밀번호 확인 일치, 비밀번호 규칙을 검증한다.
- 전화번호와 이메일은 정지/탈퇴 계정까지 포함해 재사용할 수 없다.

## 비공개 필드

- password_hash
- phone
- email
- admin_memo
- refresh token 관련 정보

## 관련 API

- `GET /api/users/me`
- `PATCH /api/users/me/profile`
- `POST /api/users/me/verify-password`
- `PATCH /api/users/me`
- `PATCH /api/users/me/password`
- `POST /api/auth/phone/send`
- `POST /api/auth/phone/verify`
