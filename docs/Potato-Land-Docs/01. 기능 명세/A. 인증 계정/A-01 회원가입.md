# A-01 회원가입

## 1. 목적

비회원이 감자나라 계정을 생성한다.

## 2. 액터

- 비회원
- SMS 인증 서버

## 3. 사전 조건

- 로그인하지 않은 사용자
- 사용 가능한 전화번호를 보유한 사용자

## 4. 정상 플로우

1. 사용자가 회원가입 페이지에 접근한다.
2. 이름, 아이디, 닉네임, 비밀번호, 비밀번호확인, 전화번호를 입력한다.
3. 아이디와 닉네임의 중복 여부를 확인한다. 
4. 이메일을 입력한 경우 이메일 중복 여부를 확인한다.
5. 전화번호 인증번호를 요청한다.
6. 서버는 인증번호를 보내고 3분동안 저장한다. 3분이 지나면 만료된다.
7. 인증번호를 입력하고 인증을 완료한다.
8. 인증번호가 일치하면 서버는 기존 인증번호 정보를 제거하고, 전화번호 인증 완료를 증명하는 인증 식별자를 새로 생성한다. 인증 완료 정보는 Redis에서 10분 동안 유지되며, 클라이언트에는 인증 식별자가 담긴 쿠키 또는 토큰이 전달된다.
9. 약관에 동의한다.
10. 회원가입을 요청한다.
11. 서버가 전체 입력값을 다시 검증한다.
12. 비밀번호를 해시한다.
13. 사용자 정보를 저장한다.
14. 회원가입 완료 화면을 표시한다.
15. 로그인 페이지로 이동한다.

## 5. 대체 플로우

- 이메일은 입력하지 않을 수 있다.
- 회원가입 완료 후 다시 로그인 해야한다.

## 6. 예외 플로우

- 아이디 중복
- 닉네임 중복
- 전화번호 중복
- 인증번호 불일치
- 인증번호 만료
- 비밀번호 규칙 불충족
- 필수 약관 미동의
- 인증 요청 횟수 초과

## 7. 상태 및 데이터 변화

- `users` 레코드 생성
- 전화번호 인증 정보 제거
- 비밀번호 해시 저장

## 8. 관련 API

- 아이디 중복 확인
- 전화번호 인증번호 발송
- 전화번호 인증번호 검증
- 회원가입
