# B. 상품 탐색

## 1. 목적

사용자가 메인 화면, 중고거래 목록, 경매 목록, 검색 결과, 상품 상세 화면에서 원하는 상품을 찾을 수 있게 한다.

## 2. 액터

- 비회원
- 로그인 사용자
- 정지되지 않은 사용자

## 3. 주요 화면

- 시작페이지 비로그인
- 시작페이지 로그인 후
- 중고거래 메인 목록
- 중고거래 검색 결과
- 경매 메인 목록
- 경매 검색 결과
- 중고거래 상세
- 경매 상세
- 판매자 프로필

## 4. 정상 플로우

1. 사용자가 메인 또는 목록 페이지에 접근한다.
2. 서버는 카테고리와 상품 목록을 조회한다.
3. 사용자는 검색어, 카테고리, 정렬, 페이지네이션 조건을 선택한다.
4. 서버는 조건에 맞는 `listings`와 상세 테이블을 조회한다.
5. 사용자가 상품 카드를 클릭하면 상세 페이지로 이동한다.
6. 상세 페이지 접근 시 조회수를 증가시킨다.

## 5. 검색/필터 정책

- 카테고리 선택 시 해당 카테고리 상품만 보여준다.
- 카테고리 선택 후 검색하면 카테고리는 전체로 되돌리는 정책을 Figma 메모 기준 후보로 둔다.
- 지역은 별도 사용자 테이블에 저장하지 않고 `listings.preferred_trade_location` 문자열로 저장한다.
- 중고거래 목록은 `used_posts.trade_status = ON_SALE` 중심으로 보여준다.
- 경매 목록은 `auction_posts.status = ON_GOING` 중심으로 보여준다.

## 6. 관심 상품

- 로그인 사용자만 관심 상품 등록/해제가 가능하다.
- 중복 관심은 `favorites(user_idx, listing_idx)` PK로 막는다.
- 삭제된 게시글/경매는 목록, 검색, 상세, 마이페이지, 외부 프로필에서 조회하지 않는다.
- 종료된 경매는 입찰과 채팅은 비활성화하지만 관심 추가는 가능하다.

## 7. 예외 플로우

- 존재하지 않는 상품
- 삭제된 상품 접근
- 비로그인 사용자의 관심 등록 요청
- 정지 사용자의 관심 등록 요청
- 잘못된 카테고리 또는 페이지 값

## 8. 관련 DB

- `listings`
- `used_posts`
- `auction_posts`
- `categories`
- `post_images`
- `favorites`
- `users`
