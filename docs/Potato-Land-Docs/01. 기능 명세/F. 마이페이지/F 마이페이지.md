# F. 마이페이지

## 1. 목적

사용자가 자신의 프로필, 판매 상품, 관심 품목, 거래 내역, 거래 후기를 확인하고 관리할 수 있게 한다.

## 2. 액터

- 로그인 사용자
- 다른 사용자의 프로필을 보는 사용자

## 3. 주요 화면

- 내 프로필
- 프로필 수정
- 판매 상품
- 관심 품목
- 거래내역
- 거래 후기
- 후기 작성
- 상대방 프로필/판매 상품
- 상대방 프로필/거래 후기

## 4. 내 마이페이지 플로우

1. 사용자가 마이페이지에 접근한다.
2. 서버는 사용자 기본 정보와 판매 상품 목록을 조회한다.
3. 사용자는 탭을 이동해 관심 품목, 거래내역, 후기를 조회한다.
4. 사용자는 프로필 수정 화면에서 닉네임, 이메일, 프로필 이미지를 수정한다.
5. 거래 완료 내역이 있으면 후기를 작성할 수 있다.

## 5. 상대방 프로필 플로우

1. 사용자가 상품 상세 또는 채팅에서 상대방 프로필로 이동한다.
2. 서버는 상대방 공개 프로필을 조회한다.
3. 판매 상품과 거래 후기를 보여준다.
4. 개인정보성 필드는 노출하지 않는다.

## 6. 노출 정책

- 공개 가능: 닉네임, 프로필 이미지, 판매 상품, 거래 후기
- 비공개: login_id, phone, email, password_hash
- 정지 사용자의 프로필은 접근 제한 또는 비활성 안내를 표시한다.

## 7. 거래 후기 정책

- 거래가 `COMPLETED`인 경우에만 후기를 작성할 수 있다.
- 한 거래에서 같은 작성자는 한 번만 후기를 작성할 수 있다.
- 평점은 1~10 사이 값만 허용한다.

## 8. 관련 DB

- `listings`
- `used_posts`
- `auction_posts`
- `favorites`
- `transactions`
- `reviews`
- `post_images`
