# F. 마이페이지

## 1. 목적

사용자가 자신의 프로필, 판매 상품, 관심 품목, 거래 내역, 거래 후기를 확인하고 관리할 수 있게 한다.

## 2. 액터

- 로그인 사용자
- 다른 사용자의 프로필을 보는 사용자

## 3. 주요 화면

- 내 프로필
- 프로필 수정
- 회원 정보 수정 전 비밀번호 확인
- 회원 정보 수정
- 판매 상품
- 관심 품목
- 거래내역
- 거래 후기
- 후기 작성
- 상대방 프로필/판매 상품
- 상대방 프로필/거래 후기

## 4. 내 마이페이지 플로우

1. 사용자가 마이페이지에 접근한다.
2. 서버는 사용자 기본 정보와 판매 상품 목록을 조회한다.
3. 사용자는 탭을 이동해 관심 품목, 거래내역, 후기를 조회한다.
4. 사용자는 프로필 수정 화면에서 프로필 이미지와 소개글을 수정한다.
5. 회원 정보 수정은 현재 비밀번호 확인 후 진입한다.
6. 회원 정보 수정 화면에서 닉네임, 이메일, 비밀번호, 전화번호를 변경할 수 있다.
7. 전화번호 변경은 새 전화번호 인증을 완료해야 저장할 수 있다.
8. 거래 완료 내역이 있으면 구매자와 판매자 모두 후기를 작성할 수 있다.

## 5. 상대방 프로필 플로우

1. 사용자가 상품 상세 또는 채팅에서 상대방 프로필로 이동한다.
2. 서버는 상대방 공개 프로필을 조회한다.
3. 판매 상품과 거래 후기를 보여준다.
4. 개인정보성 필드는 노출하지 않는다.
5. 삭제된 판매 상품은 외부 프로필에 노출하지 않는다.
6. 정지/탈퇴 사용자는 `삭제된 사용자`로 표시하고 프로필 이동을 비활성화한다.

## 6. 노출 정책

- 공개 가능: 닉네임, 프로필 이미지, 소개글, 판매 상품, 거래 후기
- 비공개: login_id, phone, email, password_hash, admin_memo
- 정지/탈퇴 사용자는 일반 사용자 화면에서 `삭제된 사용자`로 표시한다.
- 정지/탈퇴 사용자의 프로필 이미지는 기본 이미지 또는 비활성 상태로 표시한다.
- 정지/탈퇴 사용자의 프로필 이동은 비활성화한다.
- 삭제된 상품은 관심 품목 목록에서 제거된다.
- 완료 거래내역에서는 삭제된 상품의 과거 상품 정보를 보여주되 게시글 상세 이동은 비활성화한다.

## 7. 거래 후기 정책

- 거래가 `COMPLETED`인 경우에만 후기를 작성할 수 있다.
- 구매자와 판매자 모두 상대방에게 후기를 작성할 수 있다.
- 한 거래에서 같은 작성자는 한 번만 후기를 작성할 수 있다.
- 평점은 DB에서 1~10 사이 값만 허용한다.
- UI는 0.5 단위 별점 표현을 사용할 수 있다.

## 8. 회원 정보 수정 정책

- 회원 정보 수정 버튼을 누르면 먼저 현재 비밀번호 확인 화면으로 이동한다.
- 비밀번호 확인 성공 시 회원 정보 수정 화면에 진입한다.
- 닉네임 변경은 중복 검증을 거친다.
- 이메일 변경은 형식과 중복 검증을 거친다.
- 전화번호 변경은 `CHANGE_PHONE` 전화번호 인증을 완료해야 한다.
- 비밀번호 변경은 새 비밀번호와 새 비밀번호 확인 일치, 비밀번호 규칙 검증을 거친다.
- 탈퇴하기 버튼은 항상 활성화하지만 재확인 절차를 거친다.
