# 최종 문서 정본 안내

현재 구현을 읽을 때는 먼저 [[98. 최종 통합 구현 계약/00. README]]를 연다.

기존 `01~09` 문서는 기획 배경과 이전 결정을 보존하는 **역사 문서**다. 최종 코드와 이름·URL·상태·순서가 다르면 `98. 최종 통합 구현 계약`을 우선한다. 특히 다음 항목은 최종 계약으로 교체됐다.

- 회원정보 수정 증명: `editToken`
- 전화번호 소유 증명: `phoneVerificationId`
- 새 비밀번호 입력: `newPassword`, `newPasswordConfirm`
- 인증 사용자 객체: `req.user.userIdx`
- 공통 업로드: `infrastructure/uploads/upload.js`
- 경매 입찰 source of truth: PostgreSQL row lock
- 경매 실시간 cache: `auction:{listingIdx}:state`, `auction:{listingIdx}:bidders`
- canonical HTTP API: 68개

> 기존 문서를 삭제하지 않은 이유는 설계가 바뀐 경위와 팀원의 원래 의도를 추적할 수 있게 하기 위해서다. 새 개발과 검증은 반드시 `98` 폴더를 기준으로 한다.
