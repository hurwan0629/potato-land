- 회원가입 성공 후 자동 로그인하지 않는다.
- 삭제 상품은 soft delete이며 `deleted_at`과 도메인 status를 함께 사용한다.
- 거래 취소는 `transactions.status = CANCELED`로 판단한다.
- `transactions.canceled_at`, `cancel_reason`은 사용하지 않는다.
- Redis Stream Worker는 MVP가 아니라 확장 항목이다.

### 주요 변경

- 삭제된 게시글/경매 상세 직접 접근은 `404 NOT_FOUND`로 통일했다.
- 삭제된 게시글/경매는 목록, 검색, 관심목록, 마이페이지, 외부 프로필에서 제외하도록 정리했다.
- 게시글/경매 삭제 시 해당 `favorites` 행을 삭제하도록 명시했다.
- 완료 거래내역에서는 삭제 상품의 과거 상품 정보만 보여주고 상세 이동은 비활성화하도록 정리했다.
- 진행 중 경매 삭제 시 `LISTING_DELETED` 알림, Redis 상태 삭제, Timer 제거, `auction:deleted` 전송을 명시했다.
- 사용자 탈퇴/영구정지 공통 처리 서비스를 문서화했다.
- 사용자 비활성화 시 refresh session 삭제, Socket 강제 종료, REQUESTED 거래 CANCELED, 소유 진행중 경매 삭제, 최고 입찰자 재계산을 명시했다.
- 정지/탈퇴 사용자는 일반 화면에서 `삭제된 사용자`로 표시하고 프로필 이동을 비활성화하도록 정리했다.
- 비활성 사용자가 포함된 기존 채팅방은 읽기 전용으로 유지하도록 정리했다.
- 현재 채팅방을 보고 있는 수신자에게는 `NEW_MESSAGE` notification row를 저장하지 않도록 정리했다.
- `chat_messages.client_message_id`와 `UNIQUE(chat_room_idx, sender_idx, client_message_id)`를 ERD에 추가했다.
- `AUCTION_LEADER_CHANGED` 알림 타입을 추가했다.
- `auction:deleted`, `auction:leader-changed` Socket 이벤트와 payload를 추가했다.
- 최고 입찰자 비활성화 시 다음 유효 입찰자로 재계산하고, 후보가 없으면 현재가를 시작가로 복원하도록 정리했다.
- 서버 구조 보완 후보로 `database/migrations`, `database/seeds`, `notification.emitter.js`의 용도를 설명했다.
- 테스트 관련 폴더와 테스트 도구 문서는 이번 범위에서 제외했다.
