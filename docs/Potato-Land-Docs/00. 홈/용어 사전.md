# 용어 사전

## Actor

시스템 밖에서 행동을 시작하는 대상이다. 예: 사용자, 관리자, 스케줄러, 문자 발송 서비스.

## Access Token

짧은 시간 동안 API 접근 권한을 증명하는 JWT이다. 감자나라에서는 15분짜리 HttpOnly 쿠키로 사용한다.

## Refresh Token

Access Token을 다시 발급받기 위한 긴 수명의 JWT이다. 감자나라에서는 7일짜리 HttpOnly 쿠키로 사용하고 Redis에 유효성 key를 저장한다.

## Refresh Key

서버가 Redis에 저장하는 refresh token 유효성 확인용 key이다. 사용자에게 직접 주는 값이 아니다.

## Redis TTL

Redis key가 자동으로 사라지는 만료 시간이다. 전화번호 인증번호, 인증 완료 식별자, refresh key에 사용한다.

## DB Fallback

Redis 상태가 없거나 신뢰하기 어려울 때 PostgreSQL 데이터를 기준으로 서비스를 복구하거나 처리를 제한하는 정책이다. Redis snapshot/AOF와는 다르다.

## Redis Lua Script

Redis에서 여러 명령을 하나의 원자 작업처럼 실행하기 위한 script이다. 경매 입찰에서 현재가 비교와 최고입찰자 갱신을 안전하게 처리할 때 사용한다.

## Redis Stream

Redis의 append-only 이벤트 로그 자료구조이다. 입찰 성공 이벤트를 쌓고 Worker가 순서대로 DB에 저장하는 구조에 사용할 수 있다.

## Worker

사용자 요청과 별개로 백그라운드 작업을 처리하는 프로세스 또는 모듈이다. 꼭 멀티스레드라는 뜻은 아니다.

## Scheduler

정해진 주기마다 작업을 실행하는 서버 구성요소이다. 감자나라에서는 경매 종료와 낙찰 확정에 사용한다.

## Socket.IO Room

특정 사용자나 채팅방, 경매방에만 실시간 이벤트를 보내기 위한 그룹이다.

## Notification

사용자에게 보여줄 알림 데이터이다. 감자나라에서는 DB에 먼저 저장하고, 접속 중이면 Socket으로 즉시 보낸다.

## Listing

중고거래와 경매를 묶는 공통 게시글이다. 제목, 설명, 판매자, 카테고리, 희망 거래 장소를 가진다.

## Used Post

중고거래 게시글의 상세 데이터이다. 가격, 상품 상태, 거래 상태를 가진다.

## Auction Post

경매 게시글의 상세 데이터이다. 시작가, 현재가, 입찰 단위, 시작/종료 시각, 경매 상태를 가진다.

## Transaction

거래 요청, 완료, 취소를 나타내는 거래 내역이다.
