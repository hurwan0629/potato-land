# D-03 경매 삭제 시퀀스

```mermaid
sequenceDiagram
    actor U as 판매자 또는 관리자
    participant API as Express API
    participant DB as PostgreSQL
    participant R as Redis
    participant T as Auction Timer
    participant N as Notification Emitter
    participant IO as Socket.IO

    U->>API: DELETE /api/auctions/:listingIdx
    API->>API: 권한/삭제 여부 검증
    API->>DB: BEGIN
    API->>DB: listings.deleted_at/deleted_by/delete_reason 저장
    API->>DB: favorites 삭제
    API->>DB: auction_bids 기준 기존 입찰자 조회
    API->>DB: LISTING_DELETED 알림 사용자당 1회 저장
    API->>DB: COMMIT
    API->>R: auction:state:{listingIdx} 삭제
    API->>T: 경매 Timer 제거
    API->>IO: auction:deleted
    API-->>U: 삭제 성공
```

## 체크리스트

- [ ] Redis 상태 삭제
- [ ] Timer 제거
