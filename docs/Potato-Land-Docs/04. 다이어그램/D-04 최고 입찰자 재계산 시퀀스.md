# D-04 최고 입찰자 재계산 시퀀스

```mermaid
sequenceDiagram
    participant S as User Deactivation Service
    participant DB as PostgreSQL
    participant R as Redis
    participant N as Notification Emitter
    participant IO as Socket.IO

    S->>DB: 비활성 사용자가 최고 입찰자인 진행중 경매 조회
    loop 대상 경매별
        S->>DB: 다음 유효 입찰자 조회
        alt 다음 유효 입찰자 있음
            S->>DB: auction_posts.current_price/winning_bid_idx 갱신
            S->>R: Redis 최고 입찰 상태 갱신
        else 다음 유효 입찰자 없음
            S->>DB: 최고 입찰자 NULL, 현재가 시작가로 복원
            S->>R: Redis 최고 입찰자 NULL, 현재가 시작가로 복원
        end
        S->>N: AUCTION_LEADER_CHANGED 알림 저장
        S->>IO: auction:leader-changed
    end
```
