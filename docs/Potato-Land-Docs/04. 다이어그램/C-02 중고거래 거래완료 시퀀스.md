# C-02 중고거래 송금요청 거래완료 시퀀스

```mermaid
sequenceDiagram
    actor B as 구매자
    actor S as 판매자
    participant F as Frontend
    participant A as Express API
    participant D as PostgreSQL
    participant N as Notification Service
    participant IO as Socket.IO

    S->>F: 채팅에서 송금 요청
    F->>A: POST /api/transactions/payment-requests
    A->>D: 같은 상품 REQUESTED/COMPLETED 거래 중복 확인
    A->>D: transactions REQUESTED 생성
    A->>D: PAYMENT_REQUEST chat_messages 저장
    A->>N: 구매자 알림 저장
    N->>IO: notification:new
    A->>IO: chat:message:new
    A-->>F: 송금 요청 생성

    B->>F: 송금 요청 링크 클릭 후 송금
    F->>A: PATCH /api/transactions/:id/complete
    A->>D: transaction COMPLETED
    A->>D: used_posts SOLD
    A->>D: TRADE_COMPLETE 시스템 메시지 저장
    A->>N: 판매자 PAYMENT_RECEIVED 알림 저장
    A->>D: COMMIT
    A->>IO: chat:message:new
    N->>IO: notification:new
    A-->>F: 거래 완료
```

## 체크리스트

- [ ] 같은 상품 REQUESTED/COMPLETED 거래 최대 1개 보장
- [ ] 판매자/구매자 본인 확인
- [ ] 거래 완료 transaction 처리
- [ ] 판매 상태 SOLD 변경
- [ ] TRADE_COMPLETE 시스템 메시지 저장
- [ ] PAYMENT_RECEIVED 알림 통일
- [ ] 후기 작성 가능 상태로 노출
