# D-02 경매 종료 Timer 복구 시퀀스

```mermaid
sequenceDiagram
    participant T as Auction Timer
    participant C as Recovery Scheduler
    participant R as Redis
    participant D as PostgreSQL
    participant N as Notification Service
    participant IO as Socket.IO

    T->>D: 경매별 종료 시각 도달
    T->>R: Redis 경매 상태 조회
    T->>D: 최고 입찰 DB 보조 확인
    alt 입찰 있음
        T->>D: auction_posts FINISHED, winning_bid_idx 저장
        T->>N: 판매자 AUCTION_ENDED 알림 저장
        T->>N: 낙찰자 AUCTION_WON 알림 저장
        T->>IO: auction:ended
    else 입찰 없음
        T->>D: auction_posts FINISHED 저장
        T->>N: 판매자 AUCTION_ENDED_WITHOUT_BID 알림 저장
        T->>IO: auction:ended
    end

    Note over T,D: 종료 시 transactions/chat_rooms는 생성하지 않음
    Note over T,D: 판매자가 후속 송금 요청을 만들 때 낙찰자와 금액을 검증

    C->>D: 종료 누락 ON_GOING 경매 조회
    loop 누락 경매별
        C->>D: 멱등 조건으로 FINISHED 처리 시도
        alt 입찰 있음
            C->>N: 판매자 AUCTION_ENDED 알림 저장
            C->>N: 낙찰자 AUCTION_WON 알림 저장
            C->>IO: auction:ended
        else 입찰 없음
            C->>N: 판매자 AUCTION_ENDED_WITHOUT_BID 알림 저장
            C->>IO: auction:ended
        end
    end
```
