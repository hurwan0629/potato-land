# E-01 채팅 알림 시퀀스

```mermaid
sequenceDiagram
    actor A as 사용자 A
    actor B as 사용자 B
    participant F as Frontend
    participant S as Socket.IO Server
    participant D as PostgreSQL
    participant IO as Socket.IO
    participant N as Notification Service

    A->>F: 메시지 입력
    F->>S: chat:message:send
    S->>D: 채팅방 참여자 검증
    S->>D: chat_messages 저장
    alt 수신자 socket.data.activeChatRoomIdx == chatRoomIdx
        S->>S: NEW_MESSAGE 알림 저장 생략
    else 미접속 또는 다른 화면
        S->>D: NEW_MESSAGE 알림 저장
        S->>IO: notification:new
    end
    S->>D: chat_rooms.last_message_at 갱신
    S->>IO: chat:message:new
    S->>IO: chat:room:updated
    S-->>F: 메시지 전송 성공

    B->>F: 채팅방 메시지 확인
    F->>S: chat:read(chatRoomIdx)
    S->>D: 방의 저장된 NEW_MESSAGE 알림 전체 읽음 처리
    S->>IO: notification:unread-count
```
