# F-02 외부 프로필 조회

## 요청 계약

`GET /api/mypage/:userIdx`와 공개 판매상품·후기 하위 조회 API를 사용한다. 인증은 optional이며 private 필드는 응답하지 않는다.

## Frontend 순서

1. URL userIdx로 공개 프로필·판매상품·받은 후기를 조회한다.
2. `profileEnabled=false` 또는 `inactive=true`이면 프로필 이미지와 추가 이동을 비활성화한다.
3. rating은 `/ 2`해 표시한다.
4. 삭제 상품은 목록에 렌더링하지 않는다.

## Backend 조회 순서

1. userIdx 형식과 대상 존재를 확인한다.
2. 활성 사용자면 공개 nickname, 이미지, 소개와 aggregate를 DTO로 만든다.
3. 탈퇴/정지 사용자면 `displayName=삭제된 사용자`, 이미지 null, profileEnabled false를 사용한다.
4. 판매상품은 대상 seller와 `deleted_at IS NULL` 조건으로 조회한다.
5. 받은 후기는 `reviewee_idx` 기준으로 조회하며 완료 거래·삭제 상품의 과거 snapshot은 보존한다.
6. private 계정 정보는 어떤 응답에도 포함하지 않는다.

## 저장소와 동기화

- PostgreSQL만 사용한다.
- 사용자 비활성화 후에도 후기·완료 거래 row를 삭제하지 않는다.
- 프론트는 404와 비활성 DTO를 구분한다. 존재하는 비활성 사용자를 404로 바꾸지 않는다.
