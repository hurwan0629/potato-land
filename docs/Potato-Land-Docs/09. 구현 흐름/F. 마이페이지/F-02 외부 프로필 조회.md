# F-02 외부 프로필 조회

## 목적

다른 사용자의 공개 프로필, 판매상품, 리뷰를 조회한다.

## Frontend 구현 흐름

- `profileEnabled`가 false면 프로필 이동 링크를 비활성화한다.
- 비활성 사용자는 `삭제된 사용자` 표시를 따른다.
- 삭제된 게시글은 외부 프로필 판매상품에 표시하지 않는다.

## Backend 구현 흐름

- 대상 사용자를 조회한다.
- 대상 사용자가 비활성이면 DTO에서 닉네임, 프로필 이미지, 프로필 이동 가능 여부를 숨긴다.
- 외부 판매상품은 `listings.deleted_at IS NULL` 조건으로 조회한다.
- 완료된 거래와 후기는 보존하고 공개한다.

## DB 확인/변경

- `users`
- `listings`
- `reviews`
- `transactions`
