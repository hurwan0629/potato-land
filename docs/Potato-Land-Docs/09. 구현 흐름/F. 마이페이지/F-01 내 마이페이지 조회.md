# F-01 내 마이페이지 조회

## 목적

내 판매상품, 관심목록, 거래내역, 리뷰를 조회한다.

## Frontend 구현 흐름

- 탭 또는 필터 상태를 query로 전달한다.
- 삭제된 게시글은 판매상품/관심목록에 나오지 않는 것을 전제로 렌더링한다.
- 완료 거래내역에서 삭제 상품은 상세 이동을 비활성화한다.

## Backend 구현 흐름

- access token과 사용자 활성 상태를 확인한다.
- 내 판매상품은 `listings.deleted_at IS NULL` 조건으로 조회한다.
- 관심목록은 삭제된 게시글이 제거되어 있어야 하며, 조회 시에도 삭제 조건을 포함한다.
- 거래내역은 기존 거래 기록을 보존하므로 삭제 상품도 snapshot 형태로 응답할 수 있다.
- 리뷰는 거래 완료 후 작성된 양방향 리뷰를 조회한다.
