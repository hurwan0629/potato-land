# F-03 거래내역 리뷰 조회

## 목적

완료/요청/취소 거래내역과 작성 가능 후기 상태를 조회한다.

## Frontend 구현 흐름

- 거래 상태 필터를 query로 전달한다.
- `canWriteReview`가 true인 경우만 후기 작성 버튼을 표시한다.
- 삭제 상품은 제목/썸네일 snapshot을 표시하되 상세 이동은 비활성화한다.

## Backend 구현 흐름

- access token과 사용자 활성 상태를 확인한다.
- 사용자가 구매자 또는 판매자인 거래만 조회한다.
- 삭제된 게시글 row는 soft delete로 남아 있으므로 거래내역용 snapshot DTO를 만든다.
- `transactions.status === COMPLETED`이고 해당 사용자가 아직 후기를 쓰지 않았으면 `canWriteReview = true`로 응답한다.
- `transactionIdx + reviewerIdx` 기준으로 리뷰 작성 여부를 판단한다.
