# B-01 목록 검색 상세 조회

## 목적

중고글/경매글 목록, 검색, 상세 조회에서 삭제/비활성 사용자 정책을 일관되게 적용한다.

## Frontend 구현 흐름

- 목록/검색은 query 조건을 API에 전달하고 응답 items만 렌더링한다.
- 상세 접근에서 404가 오면 삭제되었거나 존재하지 않는 게시글로 처리한다.
- 비활성 사용자는 `displayName = "삭제된 사용자"`와 `profileEnabled = false`를 따른다.
- 종료된 경매는 조회는 가능하지만 입찰/채팅 버튼을 비활성화한다.

## Backend 구현 흐름

- 목록/검색/마이페이지/외부 프로필/관심목록 조회는 항상 `listings.deleted_at IS NULL`을 조건에 포함한다.
- 상세 조회도 삭제된 게시글이면 `404 NOT_FOUND`를 반환한다.
- 작성자가 비활성 사용자이면 DTO에서 닉네임과 프로필 링크를 숨긴다.
- 경매 상세는 DB 상태를 기준으로 `canBid`, `canChat`, `canFavorite`를 계산한다.
- 진행 중 경매 현재가는 Redis `auction:state:{listingIdx}`가 있으면 우선 사용하고, 없으면 DB 값을 사용한다.

## DB 확인/변경

- 조회: `listings`, `used_posts`, `auction_posts`, `users`, `post_images`, `favorites`
- 변경 없음

## Redis 확인/변경

- 조회: `auction:state:{listingIdx}` optional

## 예외 조건

- `NOT_FOUND`: 삭제 또는 존재하지 않는 게시글
