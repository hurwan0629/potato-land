# B-02 관심목록 추가 해제

## 목적

활성 사용자가 삭제되지 않은 게시글을 관심목록에 추가하거나 해제한다.

## Frontend 구현 흐름

- 로그인하지 않은 사용자는 로그인 유도 UI를 표시한다.
- 삭제/종료 정책에 따라 버튼 상태를 응답의 `canFavorite`에 맞춘다.
- 클릭 후 낙관적 UI를 쓰더라도 실패 시 원래 상태로 복구한다.

## Backend 구현 흐름

- access token과 사용자 활성 상태를 확인한다.
- 게시글 존재와 `listings.deleted_at IS NULL`을 확인한다.
- 종료된 경매는 관심 추가 가능하다.
- 삭제된 경매/게시글은 관심 추가할 수 없다.
- 추가는 중복이면 성공으로 처리하거나 `CONFLICT`로 처리한다. API 명세 기준에 맞춘다.
- 게시글/경매 삭제 시 관련 `favorites` row는 삭제된다.

## DB 확인/변경

- 조회: `listings`
- 변경: `favorites`

## Redis 확인/변경

- 없음
