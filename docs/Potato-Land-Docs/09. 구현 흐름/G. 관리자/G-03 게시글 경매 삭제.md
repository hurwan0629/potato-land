# G-03 게시글 경매 삭제

## 목적

관리자가 중고글 또는 경매글을 soft delete한다.

## Frontend 구현 흐름

- 관리자 목록/상세에서 삭제 버튼을 제공한다.
- 삭제 성공 후 목록에서 제거하거나 `deletedAt` 상태를 반영한다.
- 진행 중 경매 삭제 시 경매방 사용자는 `auction:deleted`를 수신해 버튼을 비활성화한다.

## Backend 구현 흐름

- access token과 관리자 권한을 확인한다.
- 대상 게시글이 존재하고 아직 삭제되지 않았는지 확인한다.
- DB transaction을 시작한다.
- `listings.deleted_at`, `deleted_by`, `delete_reason`을 저장한다.
- 관련 `favorites` row를 삭제한다.
- 중고글은 기존 채팅/거래/후기 기록을 보존한다.
- 경매글이 진행 중이면 `auction_bids`에서 기존 입찰자를 distinct로 조회한다.
- 진행 중 경매 입찰자에게 `LISTING_DELETED` 알림을 저장한다.
- DB commit 후 경매면 `auction:state:{listingIdx}`를 삭제한다.
- 진행 중 경매 Timer를 제거한다.
- 경매방에 `auction:deleted`를 전송한다.

## DB 확인/변경

- `listings`
- `favorites`
- `auction_bids`
- `notifications`

## Redis 확인/변경

- 경매 삭제 시 삭제: `auction:state:{listingIdx}`
