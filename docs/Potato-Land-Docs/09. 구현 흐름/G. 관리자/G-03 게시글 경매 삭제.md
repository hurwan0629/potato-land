# G-03 관리자 게시글·경매 삭제

## 원칙

관리자 endpoint도 별도 삭제 로직을 복제하지 않고 중고글 C-01, 경매 D-05의 도메인 삭제 서비스를 관리자 actor로 호출한다.

## Frontend 순서

1. 대상 타입·제목·현재 상태를 확인하고 deleteReason을 입력한다.
2. 요청 중 중복 클릭을 막는다.
3. 성공하면 관리자 목록에서 삭제 상태를 재조회한다.
4. 경매 사용자는 서버의 `auction:deleted`로 즉시 버튼을 잠근다.

## Backend 순서

1. Access Token과 DB 현재 관리자 role을 확인한다.
2. listing을 조회하고 이미 삭제된 경우를 일관되게 처리한다.
3. 공통 삭제 서비스에 `actor`, `listingIdx`, `deleteReason`을 전달한다.
4. transaction에서 soft delete, favorites 삭제, 경매 입찰자 알림을 처리한다.
5. 과거 입찰·채팅·거래·후기는 보존한다.
6. commit 후 경매 Redis state와 Timer를 정리하고 Socket/알림을 전송한다.
