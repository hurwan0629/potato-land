# G-01 관리자 대시보드

## 목적

기존 테이블을 통계 쿼리로 집계해 관리자 대시보드에 표시한다.

## Frontend 구현 흐름

- 날짜 범위와 필터를 query로 전달한다.
- 차트는 React와 JS chart library로 표시한다.
- 복잡한 실시간 통계는 MVP 범위에 넣지 않는다.

## Backend 구현 흐름

- access token과 관리자 권한을 확인한다.
- 날짜 범위를 검증한다.
- 사용자 수, 게시글 수, 경매 수, 거래 수, 일자별 가입/거래 수를 SQL로 집계한다.
- 삭제된 게시글 포함 여부는 API 항목별 정의에 맞춘다. 기본 운영 통계는 전체 생성량과 현재 활성량을 분리하는 것이 좋다.

## DB 확인/변경

- 조회: `users`, `listings`, `used_posts`, `auction_posts`, `transactions`, `reviews`
