# E-02 메시지 전송 읽음 알림

## 목적

채팅 메시지를 저장하고, 수신자가 현재 채팅방을 보고 있지 않을 때만 NEW_MESSAGE 알림을 저장한다.

## Frontend 구현 흐름

- 메시지 전송 시 `clientMessageId`를 생성한다.
- `chat:message:send` ack 성공 시 임시 메시지를 확정 메시지로 교체한다.
- `chat:message:new` 수신 시 채팅방 메시지 목록과 채팅방 목록을 갱신한다.
- 현재 채팅방에 들어오면 `chat:read`로 마지막 메시지 읽음을 전송한다.

## Backend 구현 흐름

- Socket 사용자 활성 상태를 확인한다.
- 채팅방 참여자 여부를 확인한다.
- 채팅방이 read-only인지 확인한다.
- `clientMessageId` 중복을 `chat_room_idx + sender_idx + client_message_id` 기준으로 차단한다.
- `chat_messages`를 저장한다.
- 수신자의 Socket 연결 중 `socket.data.activeChatRoomIdx === chatRoomIdx`인 연결이 있는지 확인한다.
- 보고 있으면 `NEW_MESSAGE` notification row를 만들지 않는다.
- 보고 있지 않으면 `NEW_MESSAGE` 알림을 저장하고 `notification:new`을 보낸다.
- `chat:message:new`, `chat:room:updated`를 전송한다.
- `chat:read`는 `chat_room_reads`를 갱신하고 저장된 NEW_MESSAGE가 있으면 읽음 처리한다.
