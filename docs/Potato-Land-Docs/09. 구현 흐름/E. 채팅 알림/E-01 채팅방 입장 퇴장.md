# E-01 채팅방 입장 퇴장

## 목적

채팅방 입장/퇴장 시 Socket room과 현재 보고 있는 채팅방 상태를 관리한다.

## Frontend 구현 흐름

- 채팅방 화면 진입 시 Socket 연결 후 `chat:join`을 호출한다.
- 화면 이탈 시 `chat:leave`를 호출한다.
- `READ_ONLY_CHAT` 상태면 입력창과 송금 요청 버튼을 비활성화한다.

## Backend 구현 흐름

- Socket access token과 사용자 활성 상태를 확인한다.
- `chat:join` 시 채팅방 참여자인지 확인한다.
- 삭제 게시글 또는 비활성 상대방이 있어도 기존 메시지 조회와 입장은 가능하다.
- 새 메시지 가능 여부는 별도 `readOnly` 값으로 응답한다.
- join 성공 시 `socket.join("chat:{chatRoomIdx}")`를 수행한다.
- join 성공 시 `socket.data.activeChatRoomIdx = chatRoomIdx`를 설정한다.
- `chat:leave` 또는 disconnect 시 `socket.data.activeChatRoomIdx = null`로 정리한다.
- Redis presence는 사용하지 않는다.

## DB 확인/변경

- 조회: `chat_rooms`, `listings`, `users`, `chat_room_reads`

- 없음
