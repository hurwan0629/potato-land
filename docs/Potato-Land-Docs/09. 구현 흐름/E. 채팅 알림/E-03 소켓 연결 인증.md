# E-03 소켓 연결 인증

## 목적

Socket.IO 연결 시 사용자 인증과 개인 room join을 처리한다.

## Frontend 구현 흐름

- 로그인 후 Socket.IO를 연결한다.
- 기본은 쿠키 인증이므로 `withCredentials: true`를 사용한다.
- 연결 실패 시 로그인 만료 또는 정지/탈퇴 상태를 UI에 반영한다.
- access token 만료로 연결 실패 시 refresh API를 호출한 뒤 재연결한다.

## Backend 구현 흐름

- handshake cookie의 `access_token`을 검증한다.
- fallback이 필요한 경우 handshake auth token을 검증한다.
- JWT `type === "access"`를 확인한다.
- DB에서 사용자 `deleted_at`, `banned_at`, `role`을 확인한다.
- 비활성 사용자면 연결을 거부한다.
- `socket.data.auth`, `socket.data.user`를 저장한다.
- 개인 room `user:{userIdx}`에 join한다.
- `socket.data.activeChatRoomIdx = null`, `socket.data.activeAuctionListingIdx = null`로 초기화한다.
