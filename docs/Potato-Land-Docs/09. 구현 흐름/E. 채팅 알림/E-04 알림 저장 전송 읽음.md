# E-04 알림 저장 전송 읽음

## 목적

알림을 DB에 저장하고 접속 중인 사용자에게 Socket으로 전송하며 읽음 상태를 관리한다.

## Frontend 구현 흐름

- `notification:new` 수신 시 알림 목록 또는 배지를 갱신한다.
- `notification:unread-count`는 증감값이 아니라 최종값으로 처리한다.
- 알림 클릭 또는 모두 읽음 버튼은 HTTP 읽음 API를 호출한다.

## Backend 구현 흐름

- 일반 알림은 DB `notifications`에 먼저 저장한다.
- 저장 성공 후 `user:{userIdx}` room에 `notification:new`을 전송한다.
- unread count는 DB에서 다시 계산해 `notification:unread-count`로 전송한다.
- NEW_MESSAGE는 수신자가 현재 채팅방을 보고 있을 때 DB 저장을 생략한다.
- 경매 종료/낙찰/삭제/최고입찰자 변경 알림은 사용자가 화면을 보고 있어도 DB에 남긴다.
