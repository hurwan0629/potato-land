# D-01 경매글 등록 수정 삭제

## 목적

경매글을 등록, 수정, soft delete한다.

## Frontend 구현 흐름

- 판매 가격 입력창은 시작가 `startPrice`로 처리한다.
- 등록 성공 후 상세 또는 마이페이지로 이동한다.
- 진행 중/종료 경매 모두 삭제 가능하다.
- 삭제 성공 후 상세 이동과 채팅/입찰/관심 버튼을 비활성화한다.

## Backend 구현 흐름

- access token과 사용자 활성 상태를 확인한다.
- 등록 시 `listings`, `auction_posts`, `post_images`를 transaction으로 저장한다.
- 등록 시 `auction_posts.ends_at = created_at + 24 hours`로 저장한다.
- 등록 성공 후 `auctionTimers`에 timeout handle을 등록한다.
- 수정은 작성자 본인 또는 관리자만 가능하다.
- 삭제 시 `listings.deleted_at`, `deleted_by`, `delete_reason`을 저장한다.
- 삭제 시 관련 `favorites` row를 삭제한다.
- 진행 중 경매 삭제 시 기존 입찰자에게 `LISTING_DELETED` 알림을 사용자당 1회 저장한다.
- 진행 중 경매 삭제 시 `auction:state:{listingIdx}`를 삭제하고 Timer를 제거한다.
- 경매방에 `auction:deleted`를 전송한다.
