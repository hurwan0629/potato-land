# D-05 경매 삭제

## 목적

진행 중 또는 종료된 경매를 soft delete하고 조회/입찰/채팅/관심을 차단한다.

## Frontend 구현 흐름

- 판매자 또는 관리자 화면에서 삭제 버튼을 제공한다.
- 삭제 성공 시 해당 경매 상세 이동을 막고 목록을 갱신한다.
- `auction:deleted` 수신 시 입찰/채팅/관심/송금 요청 버튼을 모두 비활성화한다.

## Backend 구현 흐름

- access token과 사용자 활성 상태를 확인한다.
- 판매자 본인 또는 관리자 권한을 확인한다.
- 경매 존재와 아직 삭제되지 않았는지 확인한다.
- DB transaction을 시작한다.
- `listings.deleted_at`, `deleted_by`, `delete_reason`을 저장한다.
- 관련 `favorites` row를 삭제한다.
- 기존 입찰/채팅/거래/후기 기록은 보존한다.
- 진행 중 경매면 `auction_bids`에서 기존 입찰자를 distinct로 조회한다.
- 기존 입찰자에게 `LISTING_DELETED` 알림을 사용자당 1회 저장한다.
- DB commit 후 `auction:state:{listingIdx}`를 삭제한다.
- 진행 중 경매 Timer를 제거한다.
- 경매방에 `auction:deleted`를 전송한다.
