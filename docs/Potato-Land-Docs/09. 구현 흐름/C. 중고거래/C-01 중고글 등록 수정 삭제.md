# C-01 중고글 등록 수정 삭제

## 목적

중고거래 게시글을 등록, 수정, soft delete한다.

## Frontend 구현 흐름

- 등록/수정 form에서 제목, 가격, 설명, 선호 거래 장소, 이미지를 검증한다.
- 이미지는 `multipart/form-data`의 `images` 필드로 보낸다.
- 삭제 성공 후 목록 또는 마이페이지로 이동한다.
- 삭제된 게시글 상세 이동은 비활성화한다.

## Backend 구현 흐름

- access token과 사용자 활성 상태를 확인한다.
- 등록 시 `listings`, `used_posts`, `post_images`를 transaction으로 저장한다.
- 수정 시 작성자 본인 또는 관리자 권한을 확인한다.
- 수정 시 삭제된 게시글이면 `404 NOT_FOUND`를 반환한다.
- 삭제 시 `listings.deleted_at`, `deleted_by`, `delete_reason`을 저장한다.
- 삭제 시 관련 `favorites` row를 삭제한다.
- 기존 채팅/거래/후기 기록은 보존한다.

## DB 확인/변경

- `listings`
- `used_posts`
- `post_images`
- `favorites`
