# C-04 후기 작성

## 목적

완료된 거래의 구매자와 판매자가 서로 후기를 1회씩 작성한다.

## Frontend 구현 흐름

- 거래내역에서 `canWriteReview`가 true인 항목만 후기 작성 버튼을 표시한다.
- 후기 작성 취소 버튼은 form을 닫는 UI 동작이며 거래 상태를 바꾸지 않는다.
- 성공 후 거래내역과 리뷰 목록을 갱신한다.

## Backend 구현 흐름

- access token과 사용자 활성 상태를 확인한다.
- `transactionIdx`가 존재하고 `COMPLETED`인지 확인한다.
- 요청자가 거래 구매자 또는 판매자인지 확인한다.
- `revieweeIdx`가 거래 상대방인지 확인한다.
- `transactionIdx + reviewerIdx` 중복을 차단한다.
- 리뷰 저장 후 상대방에게 `NEW_REVIEW` 알림을 저장/전송한다.

## DB 확인/변경

- 조회: `transactions`
- 변경: `reviews`, `notifications`
