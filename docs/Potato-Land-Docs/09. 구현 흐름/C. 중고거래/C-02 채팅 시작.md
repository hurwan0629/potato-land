# C-02 채팅 시작

## 목적

구매 희망자가 판매자와 채팅방을 생성하거나 기존 채팅방으로 이동한다.

## Frontend 구현 흐름

- 상세 화면의 채팅 버튼은 응답의 `canChat` 기준으로 활성화한다.
- 채팅 시작 API 성공 시 `chatRoomIdx`로 채팅 화면에 이동한다.
- 비활성 사용자, 삭제 게시글, 종료/삭제 경매에서는 채팅 버튼을 비활성화한다.

## Backend 구현 흐름

- access token과 사용자 활성 상태를 확인한다.
- 게시글 존재와 `listings.deleted_at IS NULL`을 확인한다.
- 판매자 본인에게 채팅 시작을 차단한다.
- 판매자 또는 구매자가 비활성 사용자이면 차단한다.
- 중고글은 판매 중 상태인지 확인한다.
- 경매는 진행 중일 때만 채팅 시작을 허용한다.
- 기존 채팅방이 있으면 재사용하고, 없으면 생성한다.
- 상대방의 `user:{userIdx}` room에 `chat:room:new`를 전송한다.

## DB 확인/변경

- 조회: `listings`, `users`, `chat_rooms`
- 변경: `chat_rooms`
