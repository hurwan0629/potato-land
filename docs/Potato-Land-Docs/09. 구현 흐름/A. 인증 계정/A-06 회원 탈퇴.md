# A-06 회원 탈퇴

## 목적

사용자를 실제 삭제하지 않고 비활성화하며, 관련 진행 중 상태를 정리한다.

## 관련 API

- `DELETE /api/users/me`

## Frontend 구현 흐름

- 탈퇴 확인 입력 또는 confirm UI를 제공한다.
- 성공 시 클라이언트 사용자 상태를 비우고 로그인 전 화면으로 이동한다.
- 열린 Socket 연결은 서버에서 끊길 수 있으므로 disconnect를 정상 처리한다.

## Backend 구현 흐름

- access token과 현재 사용자 활성 상태를 확인한다.
- DB transaction을 시작한다.
- `users.deleted_at`을 저장한다.
- 해당 사용자의 `REQUESTED` 거래를 `CANCELED`로 변경한다.
- 사용자가 소유한 진행 중 경매를 soft delete한다.
- 사용자가 최고 입찰자인 진행 중 경매를 조회해 최고 입찰자를 재계산한다.
- DB commit 후 refresh session을 삭제한다.
- 관련 `auction:state:{listingIdx}`를 삭제한다.
- 관련 `auctionTimers`를 제거한다.
- 대상 사용자 Socket 연결을 강제 종료한다.
- 경매 삭제/최고입찰자 변경 알림을 저장하고 Socket으로 전송한다.

## DB 확인/변경

- `users`
- `transactions`
- `listings`
- `auction_posts`
- `auction_bids`
- `notifications`

## Redis 확인/변경

- 삭제: `session:{sub}:*`
- 삭제: `auction:state:{listingIdx}`
