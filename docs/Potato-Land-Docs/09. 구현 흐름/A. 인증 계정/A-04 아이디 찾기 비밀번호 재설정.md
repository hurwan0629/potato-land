# A-04 아이디 찾기 비밀번호 재설정

## 목적

전화번호 인증 완료 상태를 사용해 아이디를 표시하거나 비밀번호를 재설정한다.

## 관련 API

- `POST /api/auth/find-id`
- `POST /api/auth/password/reset`

## Frontend 구현 흐름

- 아이디 찾기는 `FIND_ID` 전화번호 인증을 먼저 완료한다.
- 아이디 찾기 요청 body에는 `name`, `phone`을 보낸다.
- 성공 시 응답의 `loginId`를 팝업 또는 화면에 표시한다. SMS로 아이디를 보내지 않는다.
- 비밀번호 재설정은 `RESET_PASSWORD` 전화번호 인증을 먼저 완료한다.
- 비밀번호 재설정 body에는 `name`, `loginId`, `phone`, `newPassword`, `newPasswordConfirm`을 보낸다.

## Backend 구현 흐름

- 아이디 찾기 시 `phone:verified:{phone}:FIND_ID`를 확인한다.
- `name + phone`으로 사용자를 조회한다.
- 성공 시 loginId를 응답하고 verified key를 소비한다.
- 비밀번호 재설정 시 `phone:verified:{phone}:RESET_PASSWORD`를 확인한다.
- `name + loginId + phone`으로 사용자를 조회한다.
- 새 비밀번호를 hash 후 저장하고 verified key를 소비한다.

## Redis 확인/변경

- `phone:verified:{phone}:FIND_ID`
- `phone:verified:{phone}:RESET_PASSWORD`

## 예외 조건

- `VALIDATION_ERROR`: 인증 목적 불일치, 비밀번호 불일치
- `NOT_FOUND`: 일치하는 사용자 없음

## 구현 체크리스트

- [ ] 아이디는 SMS가 아니라 응답으로 표시
- [ ] phoneVerificationId 사용 안 함
- [ ] 성공 후 verified key 삭제
