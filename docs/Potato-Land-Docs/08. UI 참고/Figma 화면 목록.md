# Figma 화면 목록

> 원본 Figma CSS 덤프: [[08. UI 참고/Figma CSS 덤프 - 메인 마이페이지 판매상품 GETmypageid]]
>
> Figma MCP 호출 한도 때문에 실제 파일을 직접 탐색하지 못했고, 루트에 저장된 CSS 덤프를 기준으로 화면을 정리했다. 아래쪽 큰 박스로 덮이거나 감싸진 폐기 영역은 구현 기준에서 제외한다.

## 1. 공통 스타일

- 기본 배경: `#FFF9F0`
- 관리자 일부 배경: `#FFF8EE`
- 주요 색상: `#5A3A21`, `#9E7A61`, `#FFC34C`, `#FEFCF7`, `#EADFCF`, `#F5B039`, `#E65055`
- 메인 폰트: KCC-Murukmuruk
- 기본 폰트: Inter
- 일반 페이지 기준 폭: 1200px
- 관리자 데스크톱 기준 폭: 1440px

- 비밀번호 찾기

- 비밀번호 찾기 완료 상태
- 비밀번호 재설정

- 관리자 관리 대상: 회원, 경매, 중고거래 글, 낙찰 정보

## 10. 폐기/참고 제외 영역

- 큰 박스로 덮인 하단 러프 영역은 구현 기준에서 제외한다.
- `Rectangle 2356`, `Rectangle 2355`, `차트1~4`, `그래프 또는 차트 그래프` 등은 폐기 또는 러프 메모로 본다.
- Todo List 텍스트는 정책 참고만 하고 화면 확정 근거로 보지 않는다.
