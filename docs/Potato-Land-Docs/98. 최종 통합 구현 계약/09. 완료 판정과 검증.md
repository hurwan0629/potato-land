# 완료 판정과 검증

## 기능 완료 조건

하나의 URL을 완료로 표시하려면 아래를 모두 충족해야 한다.

1. 올바른 URL과 method에서 실행된다.
2. 인증·역할 정책이 Router에 명시돼 있다.
3. 입력 검증과 오류 code가 문서와 맞다.
4. DB 상태 전이와 transaction이 맞다.
5. 필요한 Redis·Socket·알림·Scheduler 부수효과가 있다.
6. 응답 DTO가 최종 계약과 맞다.
7. 최소 단위 테스트 또는 통합 검증 절차가 있다.
8. 501, mock, conflict marker, 테스트 token이 없다.

## 자동 검사

```bash
# conflict marker
git grep -nE '^(<<<<<<<|=======|>>>>>>>)'

# backend
cd backend
npm ci
npm run db:setup
npm test

# frontend
cd ../client
npm ci
npm run lint
npm run build
```

## 수동 흐름 검사

- 신규 가입 → 로그인 → refresh → 로그아웃
- 비밀번호 확인 → 일반 정보 수정
- 전화번호 인증 → 전화번호 수정
- 중고 등록 → 조회 → 수정 → 관심 → 삭제
- 경매 등록 → 동시 입찰 → 종료 → 거래 생성
- 채팅 → 송금 요청 → 완료 → 후기
- 관리자 정지 → session·상품·거래·경매 정리
- 서버 재시작 → 경매 recovery
