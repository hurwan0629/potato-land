# 함수와 파일 인덱스

## 공통

| 역할 | 정본 파일 | 주요 함수 |
|---|---|---|
| HTTP/Socket 인증 | `backend/src/common/auth/accessToken.js` | `authenticateAccessToken`, `requireAuth`, `optionalAuth`, `requireRole` |
| 호환 인증 import | `backend/src/common/middlewares/auth.middleware.js` | 정본 함수 재수출 |
| DB | `backend/src/infrastructure/database/database.js` | `query`, `withTransaction` |
| Redis | `backend/src/infrastructure/redis/redisClient.js` | `getRedisClient` |
| Upload | `backend/src/infrastructure/uploads/upload.js` | `listingImageUpload`, `chatImageUpload`, `profileImageUpload` |
| 경매 Timer | `backend/src/schedulers/auctionTimer.js` | `scheduleAuctionEnd`, `cancelAuctionEnd` |
| 경매 Recovery | `backend/src/schedulers/auctionRecoveryScheduler.js` | `startAuctionRecoveryScheduler` |

## 도메인

| 도메인 | Controller | Service | Repository | Validator |
|---|---|---|---|---|
| Main | `modules/main/main.controller.js` | `main.service.js` | `main.repository.js` | Service의 limit 검증 |
| Used | `modules/used/used.controller.js` | `used.service.js` | `used.repository.js` | `used.validator.js` |
| Auctions | `modules/auctions/auctions.controller.js` | `auctions.service.js` | `auctions.repository.js` | `auctions.validator.js` |
| Users | `modules/users/users.controller.js` | `users.service.js` | `users.repository.js` | `users.validator.js` |
| Reviews | `modules/reviews/reviews.controller.js` | `reviews.service.js` | `reviews.repository.js` | Service 입력 검증 |
| Mypage | `modules/mypage/mypage.controller.js` | `mypage.service.js` | `mypage.repository.js` | Service page/filter 검증 |
| Admin | `modules/admin/admin.controller.js` | `admin.service.js` | `admin.repository.js` | Service page/filter 검증 |

## 프런트 API 정본

- `client/src/api/http.js`: cookie/refresh 공통 요청
- `mainApi.js`, `usedApi.js`, `auctionsApi.js`, `chatApi.js`
- `mypageApi.js`, `reviewsApi.js`, `adminApi.js`
- URL query 생성은 `queryString.js`를 사용한다.
