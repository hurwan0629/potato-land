## 문서 작성 형식

각 흐름은 항상 아래 순서로 설명한다.

1. **직관적인 동작 순서**: 사용자가 무엇을 요청하고 서버가 어떤 큰 단계를 거치는지 번호로 설명한다.
2. **구체적인 구현 계약**: 실제 URL, 함수, 파일, Redis key, DB transaction, 파라미터 이름을 적는다.
3. **실패와 보상 처리**: 어느 단계에서 실패하며 DB commit 뒤 외부 부수효과가 실패할 때 어떻게 처리하는지 적는다.

이 형식은 코드 주석에도 동일하게 적용한다.
