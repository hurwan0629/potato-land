# HTTP API 상세 - 경매

## 6. 경매

### GET `/api/auctions`

Request:

```json
{
  "cookies": {
    "access_token": "optional"
  },
  "query": {
    "q": "키보드",
    "categoryIdx": 1,
    "status": "ON_GOING",
    "sort": "ending_soon",
    "page": 1,
    "limit": 10
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "items": [
      {
        "listingIdx": 2,
        "title": "경매 상품",
        "thumbnailUrl": "/resources/listings/2-1.png",
        "startPrice": 10000,
        "currentPrice": 20000,
        "status": "ON_GOING",
        "bidCount": 3,
        "endsAt": "2026-07-31T13:00:00.000Z",
        "sellerNickname": "판매자"
      }
    ],
    "page": 1,
    "limit": 10,
    "totalCount": 1,
    "totalPages": 1
  }
}
```

Exceptions:

```json
[
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "경매 목록 조회 조건이 올바르지 않습니다."
  }
]
```

### POST `/api/auctions`

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "contentType": "multipart/form-data",
  "formData": {
    "title": "경매 상품",
    "description": "경매 설명",
    "categoryIdx": 1,
    "startPrice": 10000,
    "preferredTradeLocation": "서울 강남역",
    "images": ["file1", "file2"]
  }
}
```

Success 201:

```json
{
  "success": true,
  "data": {
    "listingIdx": 2,
    "listingType": "AUCTION",
    "status": "ON_GOING",
    "startPrice": 10000,
    "currentPrice": 10000,
    "startedAt": "2026-07-30T13:00:00.000Z",
    "endsAt": "2026-07-31T13:00:00.000Z"
  }
}
```

Exceptions:

```json
[
  {
    "http": 401,
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  },
  {
    "http": 403,
    "code": "BANNED_USER",
    "message": "정지된 사용자는 경매를 등록할 수 없습니다."
  },
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "경매 정보를 확인해주세요.",
    "details": { "fields": ["title", "description", "categoryIdx", "startPrice"] }
  }
]
```

### GET `/api/auctions/:listingIdx`

Request:

```json
{
  "cookies": {
    "access_token": "optional"
  },
  "params": {
    "listingIdx": 2
  },
  "query": {}
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "listingIdx": 2,
    "listingType": "AUCTION",
    "title": "경매 상품",
    "description": "경매 설명",
    "categoryIdx": 1,
    "categoryName": "디지털",
    "startPrice": 10000,
    "currentPrice": 20000,
    "minNextBid": 21000,
    "status": "ON_GOING",
    "startedAt": "2026-07-30T13:00:00.000Z",
    "endsAt": "2026-07-31T13:00:00.000Z",
    "seller": {
      "userIdx": 2,
      "nickname": "판매자",
      "profileImageUrl": "/resources/profiles/2.png"
    },
    "highestBidder": {
      "userIdx": 3,
      "nickname": "입찰자"
    },
    "images": [
      {
        "imageIdx": 1,
        "imageUrl": "/resources/listings/2-1.png",
        "sortOrder": 1
      }
    ],
    "bidCount": 3,
    "isFavorite": false,
    "canBid": true,
    "canChat": true,
    "canFavorite": true
  }
}
```

Exceptions:

```json
[
  {
    "http": 404,
    "code": "NOT_FOUND",
    "message": "경매를 찾을 수 없습니다."
  },
  {
    "http": 503,
    "code": "REDIS_UNAVAILABLE",
    "message": "경매 상태를 불러올 수 없습니다."
  }
]
```

### PATCH `/api/auctions/:listingIdx`

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "params": {
    "listingIdx": 2
  },
  "contentType": "multipart/form-data",
  "formData": {
    "title": "수정된 경매 상품",
    "description": "수정된 설명",
    "categoryIdx": 1,
    "startPrice": 10000,
    "preferredTradeLocation": "서울역",
    "images": ["file1"]
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "listingIdx": 2,
    "updated": true,
    "updatedAt": "2026-07-30T13:10:00.000Z"
  }
}
```

Exceptions:

```json
[
  {
    "http": 403,
    "code": "FORBIDDEN",
    "message": "판매자만 수정할 수 있습니다."
  },
  {
    "http": 409,
    "code": "AUCTION_CLOSED",
    "message": "종료된 경매는 수정할 수 없습니다."
  },
  {
    "http": 409,
    "code": "CONFLICT",
    "message": "이미 입찰이 있는 경매는 시작가를 수정할 수 없습니다."
  },
  {
    "http": 404,
    "code": "NOT_FOUND",
    "message": "경매를 찾을 수 없습니다."
  }
]
```

### DELETE `/api/auctions/:listingIdx`

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "params": {
    "listingIdx": 2
  },
  "body": {
    "deleteReason": "판매자가 직접 삭제"
  }
}
```

```json
  "success": true,
  "data": {
    "listingIdx": 2,
    "deleted": true,
    "deletedAt": "2026-07-30T13:10:00.000Z",
    "deletedBy": 2,
    "notifiedBidderCount": 3
  }
}
```

Exceptions:

```json
[
  {
    "http": 403,
    "code": "FORBIDDEN",
    "message": "판매자만 삭제할 수 있습니다."
  },
  {
    "http": 404,
    "code": "NOT_FOUND",
    "message": "경매를 찾을 수 없습니다."
  }
]
```

### POST `/api/auctions/:listingIdx/bids`

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "params": {
    "listingIdx": 2
  },
  "body": {
    "bidAmount": 21000
  }
}
```

Success 201:

```json
{
  "success": true,
  "data": {
    "bidIdx": 10,
    "listingIdx": 2,
    "bidderIdx": 3,
    "bidAmount": 21000,
    "currentPrice": 21000,
    "highestBidderIdx": 3,
    "createdAt": "2026-07-30T13:10:00.000Z"
  }
}
```

Exceptions:

```json
[
  {
    "http": 401,
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  },
  {
    "http": 403,
    "code": "FORBIDDEN",
    "message": "판매자는 본인 경매에 입찰할 수 없습니다."
  },
  {
    "http": 409,
    "code": "AUCTION_CLOSED",
    "message": "종료된 경매입니다."
  },
  {
    "http": 404,
    "code": "NOT_FOUND",
    "message": "경매를 찾을 수 없습니다."
  },
  {
    "http": 409,
    "code": "BID_TOO_LOW",
    "message": "최소 입찰가보다 낮습니다.",
    "details": { "minNextBid": 21000, "currentPrice": 20000 }
  },
  {
    "http": 503,
    "code": "REDIS_UNAVAILABLE",
    "message": "현재 입찰을 처리할 수 없습니다. 잠시 후 다시 시도해주세요."
  }
]
```
