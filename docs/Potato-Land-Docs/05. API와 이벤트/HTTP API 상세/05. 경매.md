# HTTP API 상세 - 경매

## 6. 경매

### GET `/api/auctions`

Request:

```json
{
  "cookies": {
    "access_token": "optional"
  },
  "query": {
    "q": "키보드",
    "categoryIdx": 2,
    "status": "ON_GOING",
    "sort": "ENDING_SOON",
    "page": 1,
    "limit": 16
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "items": [
      {
        "listingIdx": 2,
        "listingType": "AUCTION",
        "title": "경매 상품",
        "thumbnailUrl": "/resources/listings/2-1.png",
        "category": { "categoryIdx": 2, "name": "전자기기" },
        "startPrice": 10000,
        "currentPrice": 20000,
        "displayPrice": 20000,
        "status": "ON_GOING",
        "bidCount": 3,
        "favoriteCount": 5,
        "startedAt": "2026-07-30T13:00:00.000Z",
        "endsAt": "2026-07-31T13:00:00.000Z",
        "hasMyBid": true,
        "myBidAmount": 19000
      }
    ],
    "page": 1,
    "limit": 16,
    "totalCount": 1,
    "totalPages": 1
  }
}
```

Exceptions:

```json
[
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "경매 목록 조회 조건이 올바르지 않습니다."
  }
]
```

### POST `/api/auctions`

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "contentType": "multipart/form-data",
  "formData": {
    "title": "경매 상품",
    "description": "경매 설명",
    "categoryIdx": 2,
    "productStatus": "LIKE_NEW",
    "startPrice": 10000,
    "preferredTradeLocation": "서울 강남역",
```

### GET `/api/auctions/:listingIdx/bids`

Request:

```json
{
  "cookies": {
    "access_token": "optional"
  },
  "params": {
    "listingIdx": 2
  },
  "query": {}
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "bids": [
      {
        "bidIdx": 10,
        "bidderIdx": 3,
        "bidderNickname": "입찰자",
        "bidAmount": 21000,
        "createdAt": "2026-07-30T13:10:00.000Z"
      }
    ],
    "myBid": {
      "bidIdx": 8,
      "bidAmount": 19000,
      "rank": 2,
      "isInTop5": true,
      "createdAt": "2026-07-30T13:05:00.000Z"
    },
    "totalBidCount": 3
  }
}
```

Exceptions:

```json
[
  {
    "http": 404,
    "code": "NOT_FOUND",
    "message": "경매를 찾을 수 없습니다."
  }
]
```

Rules:

- 공개 입찰 현황은 금액이 높은 순서의 상위 5개를 `bids`로 응답한다.
- 로그인 사용자의 최고 입찰은 상위 5개 밖에 있어도 `myBid`로 별도 응답하며, 입찰하지 않았으면 `null`이다.
- 등록/수정 이미지의 최대 개수는 4장이다.
- 경매 수정은 진행 중인 경매의 제목, 설명, 카테고리, 상품 상태, 희망 거래 위치, 이미지만 허용한다.
- 시작가·현재가·입찰 단위·시작/종료 시각은 생성 후 변경할 수 없다.
- 진행 중 경매의 논리 삭제는 가능하다. 입찰 이력은 보존하고 타이머/Redis 상태를 정리한 뒤 입찰자에게 알린다.
