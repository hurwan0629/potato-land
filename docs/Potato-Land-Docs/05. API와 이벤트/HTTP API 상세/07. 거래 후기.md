# HTTP API 상세 - 거래/후기

## 8. 거래/후기

### POST `/api/transactions/payment-requests`

판매자가 채팅에서 구매자에게 송금 요청을 만들 때 호출한다.

경매에서는 종료 시 거래를 자동 생성하지 않는다. 판매자가 이 API를 호출하면 서버가 DB 낙찰자와 최종 낙찰가를 검증하고 정산 채팅방을 생성 또는 재사용한 뒤 거래를 만든다.

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "body": {
    "listingIdx": 1,
    "buyerIdx": 3,
    "amount": 10000,
    "message": "송금 요청드립니다."
  }
}
```

Success 201:

```json
{
  "success": true,
  "data": {
    "transactionIdx": 1,
    "listingIdx": 1,
    "sellerIdx": 2,
    "buyerIdx": 3,
    "amount": 10000,
    "status": "REQUESTED",
    "chatMessageIdx": 12,
    "createdAt": "2026-07-30T13:00:00.000Z"
  }
}
```

Exceptions:

```json
[
  {
    "http": 403,
    "code": "FORBIDDEN",
    "message": "판매자만 송금 요청을 만들 수 있습니다."
  },
  {
    "http": 409,
    "code": "CONFLICT",
    "message": "같은 구매자에게 이미 진행 중인 송금 요청이 있습니다."
  },
  {
    "http": 404,
    "code": "NOT_FOUND",
    "message": "게시글을 찾을 수 없습니다."
  },
  {
    "http": 409,
    "code": "INACTIVE_USER",
    "message": "비활성화된 사용자에게 송금 요청을 만들 수 없습니다."
  }
]
```

### GET `/api/transactions/:transactionIdx`

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "params": {
    "transactionIdx": 1
  },
  "query": {}
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "transactionIdx": 1,
    "listing": {
      "listingIdx": 1,
      "title": "감자 키보드",
      "thumbnailUrl": "/resources/listings/1-1.png"
    },
    "seller": {
      "userIdx": 2,
      "nickname": "판매자"
    },
    "buyer": {
      "userIdx": 3,
      "nickname": "구매자"
    },
    "amount": 10000,
    "status": "REQUESTED",
    "requestedAt": "2026-07-30T13:00:00.000Z",
    "completedAt": null,
    "canceledBy": null,
    "updatedAt": "2026-07-30T13:00:00.000Z"
  }
}
```

Exceptions:

```json
[
  {
    "http": 403,
    "code": "FORBIDDEN",
    "message": "거래 참여자만 조회할 수 있습니다."
  },
  {
    "http": 404,
    "code": "NOT_FOUND",
    "message": "거래 정보를 찾을 수 없습니다."
  }
]
```

### PATCH `/api/transactions/:transactionIdx/complete`

구매자가 송금 완료 버튼을 누를 때 호출한다.

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "params": {
    "transactionIdx": 1
  },
  "body": {
    "confirm": true
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "transactionIdx": 1,
    "status": "COMPLETED",
    "completedAt": "2026-07-30T13:10:00.000Z",
    "listingStatus": "SOLD",
    "systemMessageType": "TRADE_COMPLETE",
    "sellerNotificationType": "PAYMENT_RECEIVED"
  }
}
```

Exceptions:

```json
[
  {
    "http": 403,
    "code": "FORBIDDEN",
    "message": "구매자만 송금을 완료할 수 있습니다."
  },
  {
    "http": 409,
    "code": "CONFLICT",
    "message": "이미 완료되었거나 취소된 송금 요청입니다."
  }
]
```

완료 transaction 안에서 중고거래는 `used_posts.trade_status = SOLD`, 채팅은 `TRADE_COMPLETE` 시스템 메시지, 판매자 알림은 `PAYMENT_RECEIVED`로 저장한다. 경매는 이미 `FINISHED`이므로 경매 상태를 다시 변경하지 않는다.

### PATCH `/api/transactions/:transactionIdx/cancel`

판매자가 송금 요청을 취소할 때 호출한다.

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "params": {
    "transactionIdx": 1
  },
  "body": {}
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "transactionIdx": 1,
    "status": "CANCELED",
    "canceledBy": 2,
    "updatedAt": "2026-07-30T13:10:00.000Z",
    "buyerNotificationType": "PAYMENT_CANCELED"
  }
}
```

Exceptions:

```json
[
  {
    "http": 403,
    "code": "FORBIDDEN",
    "message": "판매자만 송금 요청을 취소할 수 있습니다."
  },
  {
    "http": 409,
    "code": "CONFLICT",
    "message": "이미 완료되었거나 취소된 송금 요청입니다."
  }
]
```

취소 transaction 안에서 구매자에게 `PAYMENT_CANCELED` 알림을 저장한다. `TRADE_COMPLETE` 메시지는 생성하지 않는다.

### POST `/api/reviews`

구매자와 판매자 모두 완료 거래에 대해 서로에게 1회씩 작성할 수 있다.

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "body": {
    "transactionIdx": 1,
    "revieweeIdx": 2,
    "rating": 9,
    "content": "좋은 거래였습니다."
  }
}
```

Success 201:

```json
{
  "success": true,
  "data": {
    "reviewIdx": 1,
    "transactionIdx": 1,
    "reviewerIdx": 3,
    "revieweeIdx": 2,
    "rating": 9,
    "content": "좋은 거래였습니다.",
    "createdAt": "2026-07-30T13:10:00.000Z"
  }
}
```

Exceptions:

```json
[
  {
    "http": 403,
    "code": "FORBIDDEN",
    "message": "거래 참여자만 후기를 작성할 수 있습니다."
  },
  {
    "http": 409,
    "code": "CONFLICT",
    "message": "완료된 거래에만 후기를 작성할 수 있습니다."
  },
  {
    "http": 409,
    "code": "CONFLICT",
    "message": "이미 후기를 작성했습니다."
  },
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "별점은 1 이상 10 이하의 정수여야 합니다.",
    "details": { "field": "rating" }
  }
]
```

### GET `/api/users/:userIdx/reviews`

Request:

```json
{
  "cookies": {
    "access_token": "optional"
  },
  "params": {
    "userIdx": 2
  },
  "query": {
    "type": "ALL",
    "page": 1,
    "limit": 9
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "items": [
      {
        "reviewIdx": 1,
        "transactionIdx": 1,
        "reviewerIdx": 3,
        "reviewerNickname": "구매자",
        "revieweeIdx": 2,
        "rating": 9,
        "content": "좋은 거래였습니다.",
        "listingTitle": "감자 키보드",
        "reviewType": "BUYER_REVIEW",
        "createdAt": "2026-07-30T13:10:00.000Z"
      }
    ],
    "page": 1,
    "limit": 9,
    "totalCount": 1,
    "totalPages": 1
  }
}
```

후기 rating과 평균은 API/DB에서 1~10을 사용한다. 프론트 UI만 `/ 2`해 0.5~5점으로 표시한다.

Exceptions:

```json
[
  {
    "http": 404,
    "code": "NOT_FOUND",
    "message": "사용자를 찾을 수 없습니다."
  }
]
```
