# HTTP API 상세 - 채팅

## 7. 채팅

### GET `/api/chats`

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "query": {
    "page": 1,
    "limit": 20
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "items": [
      {
        "chatRoomIdx": 1,
        "listingIdx": 1,
        "listingTitle": "감자 키보드",
        "listingThumbnailUrl": "/resources/listings/1-1.png",
        "opponentIdx": 2,
        "opponentNickname": "판매자",
        "lastMessage": {
          "messageIdx": 10,
          "messageType": "TEXT",
          "content": "안녕하세요",
          "createdAt": "2026-07-30T13:00:00.000Z"
        },
        "unreadCount": 2,
        "updatedAt": "2026-07-30T13:00:00.000Z"
      }
    ],
    "page": 1,
    "limit": 20,
    "totalCount": 1,
    "totalPages": 1
  }
}
```

Exceptions:

```json
[
  {
    "http": 401,
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  }
]
```

### POST `/api/chats`

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "body": {
    "listingIdx": 1
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "chatRoomIdx": 1,
    "listingIdx": 1,
    "sellerIdx": 2,
    "buyerIdx": 3,
    "created": false
  }
}
```

Exceptions:

```json
[
  {
    "http": 403,
    "code": "FORBIDDEN",
    "message": "본인 게시글에는 채팅을 만들 수 없습니다."
  },
  {
    "http": 404,
    "code": "NOT_FOUND",
    "message": "게시글을 찾을 수 없습니다."
  },
  {
    "http": 409,
    "code": "AUCTION_CLOSED",
    "message": "종료된 경매는 채팅을 시작할 수 없습니다."
  },
  {
    "http": 409,
    "code": "INACTIVE_USER",
    "message": "비활성화된 사용자와 새 채팅방을 만들 수 없습니다."
  }
]
```

### GET `/api/chats/:chatRoomIdx`

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "params": {
    "chatRoomIdx": 1
  },
  "query": {}
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "chatRoomIdx": 1,
    "listing": {
      "listingIdx": 1,
      "listingType": "USED",
      "title": "감자 키보드",
      "thumbnailUrl": "/resources/listings/1-1.png",
        "status": "ON_SALE",
        "deleted": false,
        "detailLinkEnabled": true
    },
    "seller": {
      "userIdx": 2,
      "nickname": "판매자",
      "displayName": "판매자",
      "profileEnabled": true
    },
    "buyer": {
      "userIdx": 3,
      "nickname": "구매자",
      "displayName": "구매자",
      "profileEnabled": true
    },
    "lastReadMessageIdx": 100,
    "canSendMessage": true,
    "canCreatePaymentRequest": true,
    "readOnly": false,
      "readOnlyReason": null
  }
}
```

종료 경매의 일반 채팅은 read-only다. 단, 판매자가 낙찰자를 대상으로 만든 `REQUESTED` 거래에 연결된 정산 채팅방은 판매자와 낙찰자에게 쓰기를 허용한다.

Exceptions:

```json
[
  {
    "http": 403,
    "code": "FORBIDDEN",
    "message": "채팅방 참여자만 조회할 수 있습니다."
  },
  {
    "http": 404,
    "code": "NOT_FOUND",
    "message": "채팅방을 찾을 수 없습니다."
  }
]
```

### GET `/api/chats/:chatRoomIdx/messages`

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "params": {
    "chatRoomIdx": 1
  },
  "query": {
    "page": 1,
    "limit": 30
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "items": [
      {
        "messageIdx": 10,
        "chatRoomIdx": 1,
        "senderIdx": 2,
      "messageType": "TEXT",
      "content": "안녕하세요",
      "clientMessageId": "temp-uuid-1",
      "imageUrl": null,
      "transactionIdx": null,
      "createdAt": "2026-07-30T13:00:00.000Z"
      }
    ],
    "page": 1,
    "limit": 30,
    "totalCount": 1,
    "totalPages": 1
  }
}
```

거래 완료 시 서버가 저장하는 시스템 메시지는 `messageType = TRADE_COMPLETE`이고 `transactionIdx`를 포함한다. 클라이언트가 이 타입을 직접 전송할 수 없다.

Exceptions:

```json
[
  {
    "http": 403,
    "code": "FORBIDDEN",
    "message": "채팅방 참여자만 메시지를 조회할 수 있습니다."
  }
]
```

### POST `/api/chats/:chatRoomIdx/messages/images`

채팅 텍스트는 Socket `chat:message:send`로 전송한다. 이 API는 이미지 메시지 업로드 전용이다.

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "params": {
    "chatRoomIdx": 1
  },
  "contentType": "multipart/form-data",
  "formData": {
    "image": "file"
  }
}
```

Success 201:

```json
{
  "success": true,
  "data": {
    "messageIdx": 11,
    "chatRoomIdx": 1,
    "messageType": "IMAGE",
    "imageUrl": "/resources/chats/11.png",
    "createdAt": "2026-07-30T13:00:00.000Z"
  }
}
```

Exceptions:

```json
[
  {
    "http": 400,
    "code": "UPLOAD_FAILED",
    "message": "채팅 이미지 업로드에 실패했습니다."
  },
  {
    "http": 403,
    "code": "FORBIDDEN",
    "message": "채팅방 참여자만 이미지를 보낼 수 있습니다."
  },
  {
    "http": 409,
    "code": "CONFLICT",
    "message": "현재 채팅을 보낼 수 없는 상태입니다."
  },
  {
    "http": 409,
    "code": "READ_ONLY_CHAT",
    "message": "읽기 전용 채팅방입니다."
  },
  {
    "http": 409,
    "code": "INACTIVE_USER",
    "message": "비활성화된 사용자가 포함된 채팅방입니다."
  }
]
```
