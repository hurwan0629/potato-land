# HTTP API 상세 - 중고거래

## 5. 중고거래

### GET `/api/used`

Request:

```json
{
  "cookies": {
    "access_token": "optional"
  },
  "query": {
    "q": "키보드",
    "categoryIdx": 2,
    "status": "ON_SALE",
    "sort": "LATEST",
    "page": 1,
    "limit": 16
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "items": [
      {
        "listingIdx": 1,
        "listingType": "USED",
        "title": "감자 키보드",
        "thumbnailUrl": "/resources/listings/1-1.png",
        "category": { "categoryIdx": 2, "name": "전자기기" },
        "displayPrice": 10000,
        "status": "ON_SALE",
        "favoriteCount": 3,
        "createdAt": "2026-07-30T13:00:00.000Z"
      }
    ],
    "page": 1,
    "limit": 16,
    "totalCount": 1,
    "totalPages": 1
  }
}
```

Exceptions:

```json
[
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "목록 조회 조건이 올바르지 않습니다."
  }
]
```

### POST `/api/used`

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "contentType": "multipart/form-data",
  "formData": {
    "title": "감자 키보드",
    "description": "상태 좋습니다.",
    "categoryIdx": 2,
    "productStatus": "LIKE_NEW",
    "price": 10000,
    "preferredTradeLocation": "서울 강남역",
    "images": ["file1", "file2"]
  }
}
```

Success 201:

```json
{
  "success": true,
  "data": {
    "listingIdx": 1,
    "listingType": "USED",
    "tradeStatus": "ON_SALE",
    "createdAt": "2026-07-30T13:00:00.000Z"
  }
}
```

Exceptions:

```json
[
  {
    "http": 401,
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  },
  {
    "http": 403,

  },
  {
    "http": 400,
    "code": "VALIDATION_ERROR",

```

### PATCH `/api/used/:listingIdx`

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "params": {
    "listingIdx": 1
  },
  "contentType": "multipart/form-data",
  "formData": {
    "title": "수정된 감자 키보드",
    "description": "설명 수정",
    "categoryIdx": 2,
    "productStatus": "USED",
    "price": 12000,
    "preferredTradeLocation": "서울역",
    "images": ["file1"]
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "listingIdx": 1,
    "updated": true,
    "updatedAt": "2026-07-30T13:10:00.000Z"
  }
}
```

Exceptions:

```json
[
  {
    "http": 401,
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  },
  {
    "http": 403,
    "code": "FORBIDDEN",
    "message": "판매자만 수정할 수 있습니다."
  },
  {
    "http": 409,
    "code": "CONFLICT",
    "message": "판매 완료된 상품은 수정할 수 없습니다."
  },
  {
    "http": 404,
    "code": "NOT_FOUND",
    "message": "게시글을 찾을 수 없습니다."
  }
]
```

Rules:

- `images`는 정렬 순서대로 최대 4장까지 받는다.
- `productStatus`는 중고와 경매가 함께 사용하는 상품 상태이며 `description`과 분리한다.
- 목록의 가격은 공통 필드 `displayPrice`로 응답하고, 상세 조회에서만 `price`를 함께 제공한다.

### DELETE `/api/used/:listingIdx`

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "params": {
    "listingIdx": 1
  },
  "body": {
    "deleteReason": "판매자가 직접 삭제"
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "listingIdx": 1,
    "deleted": true,
    "deletedAt": "2026-07-30T13:10:00.000Z",
    "deletedBy": 2
  }
}
```

Exceptions:

```json
[
  {
    "http": 403,
    "code": "FORBIDDEN",
    "message": "판매자만 삭제할 수 있습니다."
  },
  {
    "http": 404,
    "code": "NOT_FOUND",
    "message": "게시글을 찾을 수 없습니다."
  }
]
```
