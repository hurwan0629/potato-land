# HTTP API 상세 - 사용자/프로필

## 3. 사용자/프로필

### GET `/api/users/:userIdx/profile`

Request:

```json
{
  "cookies": {
    "access_token": "optional"
  },
  "params": {
    "userIdx": 2
  },
  "query": {}
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "userIdx": 2,
    "nickname": "판매자",
    "profileImageUrl": "/resources/profiles/2.png",
    "bio": "상태 메시지",
    "sellCount": 3,
    "buyCount": 5,
    "averageRating": 4.8,
    "reviewCount": 10
  }
}
```

Exceptions:

```json
[
  {
    "http": 404,
    "code": "NOT_FOUND",
    "message": "사용자를 찾을 수 없습니다."
  },
  {
    "http": 403,
    "code": "BANNED_USER",
    "message": "조회할 수 없는 사용자입니다."
  }
]
```

### GET `/api/users/me`

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "query": {}
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "userIdx": 1,
    "name": "홍길동",
    "loginId": "potato123",
    "nickname": "감자왕",
    "phone": "01012345678",
    "email": "user@example.com",
    "profileImageUrl": "/resources/profiles/1.png",
    "bio": "상태 메시지",
    "role": "USER"
  }
}
```

Exceptions:

```json
[
  {
    "http": 401,
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  },
  {
    "http": 403,
    "code": "BANNED_USER",
    "message": "이용이 제한된 계정입니다."
  }
]
```

### PATCH `/api/users/me/profile`

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "contentType": "multipart/form-data",
  "formData": {
    "profileImage": "file optional",
    "bio": "상태 메시지 optional"
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "profileImageUrl": "/resources/profiles/1.png",
    "bio": "상태 메시지"
  }
}
```

Exceptions:

```json
[
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "수정할 값이 없습니다."
  },
  {
    "http": 400,
    "code": "UPLOAD_FAILED",
    "message": "이미지 업로드에 실패했습니다.",
    "details": { "field": "profileImage" }
  },
  {
    "http": 401,
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  }
]
```

### POST `/api/users/me/verify-password`

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "body": {
    "password": "현재비밀번호"
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "verified": true,
    "verificationToken": "member_edit_verification_token",
    "expiresInSeconds": 600
  }
}
```

Exceptions:

```json
[
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "비밀번호를 입력해주세요.",
    "details": { "field": "password" }
  },
  {
    "http": 401,
    "code": "INVALID_CREDENTIALS",
    "message": "비밀번호가 일치하지 않습니다."
  },
  {
    "http": 401,
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  }
]
```

### PATCH `/api/users/me`

회원 정보 수정 전 비밀번호 확인 성공이 필요하다.

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "body": {
    "verificationToken": "member_edit_verification_token",
    "nickname": "새닉네임",
    "email": "new@example.com",
    "phone": "01099998888"
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "userIdx": 1,
    "nickname": "새닉네임",
    "email": "new@example.com",
    "phone": "01099998888"
  }
}
```

Exceptions:

```json
[
  {
    "http": 401,
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  },
  {
    "http": 401,
    "code": "MEMBER_EDIT_VERIFICATION_REQUIRED",
    "message": "비밀번호 확인이 필요합니다."
  },
  {
    "http": 409,
    "code": "CONFLICT",
    "message": "이미 사용 중인 닉네임입니다.",
    "details": { "field": "nickname" }
  },
  {
    "http": 409,
    "code": "CONFLICT",
    "message": "이미 사용 중인 이메일입니다.",
    "details": { "field": "email" }
  },
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "전화번호 변경 인증이 완료되지 않았습니다.",
    "details": { "field": "phone", "purpose": "CHANGE_PHONE" }
  }
]
```

### PATCH `/api/users/me/password`

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "body": {
    "verificationToken": "member_edit_verification_token",
    "newPassword": "NewPassword123!",
    "newPasswordConfirm": "NewPassword123!"
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "changed": true
  }
}
```

Exceptions:

```json
[
  {
    "http": 401,
    "code": "MEMBER_EDIT_VERIFICATION_REQUIRED",
    "message": "비밀번호 확인이 필요합니다."
  },
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "비밀번호와 비밀번호 확인이 일치하지 않습니다.",
    "details": { "field": "newPasswordConfirm" }
  },
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "비밀번호 형식이 올바르지 않습니다.",
    "details": { "field": "newPassword" }
  }
]
```

### DELETE `/api/users/me`

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "body": {
    "password": "현재비밀번호"
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "deleted": true,
    "deletedAt": "2026-07-30T13:00:00.000Z"
  }
}
```

Set-Cookie:

```text
access_token=; Max-Age=0; Path=/; HttpOnly; SameSite=Lax
refresh_token=; Max-Age=0; Path=/api/auth/refresh; HttpOnly; SameSite=Lax
```

Exceptions:

```json
[
  {
    "http": 401,
    "code": "INVALID_CREDENTIALS",
    "message": "비밀번호가 일치하지 않습니다."
  },
  {
    "http": 409,
    "code": "CONFLICT",
    "message": "진행 중인 거래 또는 경매가 있어 탈퇴할 수 없습니다."
  }
]
```
