# HTTP API 상세 - 사용자/프로필

## 3. 사용자/프로필

### GET `/api/users/:userIdx/profile`

Request:

```json
{
  "cookies": {
    "access_token": "optional"
  },
  "params": {
    "userIdx": 2
  },
  "query": {}
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "userIdx": 2,
    "nickname": "판매자",
    "profileImageUrl": "/resources/profiles/2.png",
    "bio": "상태 메시지",
    "sellCount": 3,
    "buyCount": 5,
    "averageRating": 9.6,
    "reviewCount": 10
  }
}
```

`averageRating`은 API에서 10점 기준 원본이다. UI에서만 `/ 2`해 5점 별점으로 표시한다.

Exceptions:

```json
[
  {
    "http": 404,
    "code": "NOT_FOUND",
    "message": "사용자를 찾을 수 없습니다."
  }
]
```

정지·탈퇴 사용자의 직접 프로필은 존재 여부를 구분하지 않고 `404 NOT_FOUND`로 처리한다.

### GET `/api/users/me`

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "query": {}
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "userIdx": 1,
    "name": "홍길동",
    "loginId": "potato123",
    "nickname": "감자왕",
    "phone": "01012345678",
    "email": "user@example.com",
    "profileImageUrl": "/resources/profiles/1.png",
    "bio": "상태 메시지",
    "role": "USER",
    "sellCount": 3,
    "buyCount": 5,
    "averageRating": 9.6,
    "reviewCount": 10
  }
}
```

Exceptions:

```json
[
  {
    "http": 401,
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  },
  {
    "http": 403,
    "code": "BANNED_USER",
    "message": "이용이 제한된 계정입니다."
  }
]
```

### PATCH `/api/users/me/profile`

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "contentType": "multipart/form-data",
  "formData": {
    "profileImage": "file optional",
    "bio": "상태 메시지 optional"
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "profileImageUrl": "/resources/profiles/1.png",
    "bio": "상태 메시지"
  }
}
```

Exceptions:

```json
[
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "수정할 값이 없습니다."
  },
  {
    "http": 400,
    "code": "UPLOAD_FAILED",
    "message": "이미지 업로드에 실패했습니다.",
    "details": { "field": "profileImage" }
  },
  {
    "http": 401,
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  }
]
```

### POST `/api/users/me/verify-password`

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "body": {
    "password": "현재비밀번호"
  }
}
```

화면에 보이는 `loginId`는 현재 로그인 사용자 정보에서 표시하며 요청 body에는 다시 받지 않는다.

Success 200:

```json
{
  "success": true,
  "data": {
    "verified": true,
    "verificationToken": "member_edit_verification_token",
    "expiresInSeconds": 600
  }
}
```

Exceptions:

```json
[
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "비밀번호를 입력해주세요.",
    "details": { "field": "password" }
  },
  {
    "http": 401,
    "code": "INVALID_CREDENTIALS",
    "message": "비밀번호가 일치하지 않습니다."
  },
  {
    "http": 401,
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  }
]
```

### PATCH `/api/users/me`

회원 정보 수정 전 비밀번호 확인 성공이 필요하다.

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "body": {
    "verificationToken": "member_edit_verification_token",
    "nickname": "새닉네임",
    "email": "new@example.com",
    "phone": "01099998888",
    "phoneVerificationId": "phone-verification-uuid",
    "newPassword": "NewPassword123!",
    "newPasswordConfirm": "NewPassword123!"
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "userIdx": 1,
    "nickname": "새닉네임",
    "email": "new@example.com",
    "phone": "01099998888",
    "passwordChanged": true
  }
}
```

Exceptions:

```json
[
  {
    "http": 401,
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  },
  {
    "http": 401,
    "code": "MEMBER_EDIT_VERIFICATION_REQUIRED",
    "message": "비밀번호 확인이 필요합니다."
  },
  {
    "http": 409,
    "code": "CONFLICT",
    "message": "이미 사용 중인 닉네임입니다.",
    "details": { "field": "nickname" }
  },
  {
    "http": 409,
    "code": "CONFLICT",
    "message": "이미 사용 중인 이메일입니다.",
    "details": { "field": "email" }
  },
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "전화번호 변경 인증이 완료되지 않았습니다.",
    "details": { "field": "phone", "purpose": "CHANGE_PHONE" }
  },
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "비밀번호와 비밀번호 확인이 일치하지 않습니다.",
    "details": { "field": "newPasswordConfirm" }
  },
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "비밀번호 형식이 올바르지 않습니다.",
    "details": { "field": "newPassword" }
  }
]
```

`verificationToken`은 항상 필수다. `phone`을 보내면 같은 번호의 `CHANGE_PHONE`용 `phoneVerificationId`가 필수이며, `newPassword`를 보내면 `newPasswordConfirm`이 필수다. 보내지 않은 선택 필드는 기존 값을 유지한다. 성공한 commit 뒤 회원정보 수정 token과 사용한 전화번호 verified key를 폐기한다.

### DELETE `/api/users/me`

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "body": {
    "password": "현재비밀번호"
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "deleted": true,
    "deletedAt": "2026-07-30T13:00:00.000Z",
    "deletedListingCount": 2,
    "canceledTransactionCount": 1,
    "recalculatedAuctionCount": 1
  }
}
```

Set-Cookie:

```text
access_token=; Max-Age=0; Path=/; HttpOnly; SameSite=Lax
refresh_token=; Max-Age=0; Path=/api/auth/refresh; HttpOnly; SameSite=Lax
```

Exceptions:

```json
[
  {
    "http": 401,
    "code": "INVALID_CREDENTIALS",
    "message": "비밀번호가 일치하지 않습니다."
  }
]
```

탈퇴 전 화면은 진행 중인 글·거래·입찰이 정리된다는 점을 재확인한다. 서버는 한 transaction에서
사용자와 소유 글을 논리 삭제하고 진행 송금 요청을 취소하며, 탈퇴자의 입찰 이력은 보존하되
최고 입찰자 계산에서 제외한다. commit 후 session, 경매 Timer/Redis 상태를 정리하고 관련 사용자에게 알린다.
