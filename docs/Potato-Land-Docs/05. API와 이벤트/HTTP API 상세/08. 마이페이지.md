# HTTP API 상세 - 마이페이지

## 9. 마이페이지

### GET `/api/mypage/me/listings`

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "query": {
    "type": "ALL",
    "status": "ON_SALE",
    "page": 1,
    "limit": 5
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "items": [
      {
        "listingIdx": 1,
        "listingType": "USED",
        "title": "감자 키보드",
        "thumbnailUrl": "/resources/listings/1-1.png",
        "displayPrice": 10000,
        "status": "ON_SALE",
        "createdAt": "2026-07-30T13:00:00.000Z"
      }
    ],
    "page": 1,
    "limit": 5,
    "totalCount": 1,
    "totalPages": 1
  }
}
```

Exceptions:

```json
[
  {
    "http": 401,
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  }
]
```

### GET `/api/mypage/me/history`

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "query": {
    "type": "ALL",
    "status": "COMPLETED",
    "q": "키보드",
    "page": 1,
    "limit": 10
  }
}
```

### GET `/api/mypage/:userIdx/listings`

```json
{
  "cookies": {
    "access_token": "optional"
  },
  "params": {
    "userIdx": 2
  },
  "query": {
    "type": "ALL",
    "page": 1,
    "limit": 5
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "items": [
      {
        "listingIdx": 1,
        "listingType": "USED",
        "title": "감자 키보드",
        "thumbnailUrl": "/resources/listings/1-1.png",
        "displayPrice": 10000,
        "status": "ON_SALE",
        "createdAt": "2026-07-30T13:00:00.000Z"
      }
    ],
    "page": 1,
```
