# HTTP API 상세 - 마이페이지

## 9. 마이페이지

### GET `/api/mypage/me/listings`

Request:

```json
{
  "cookies": {
    "access_token": "access.jwt.value"
  },
  "query": {
    "type": "ALL",
    "status": "ON_SALE",
    "page": 1,
    "limit": 5
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "items": [
      {
        "listingIdx": 1,
        "listingType": "USED",
        "title": "감자 키보드",
        "thumbnailUrl": "/resources/listings/1-1.png",
        "displayPrice": 10000,
        "status": "ON_SALE",
        "createdAt": "2026-07-30T13:00:00.000Z"
      }
    ],
    "page": 1,
    "limit": 5,
    "totalCount": 1,
    "totalPages": 1
  }
}
```

Exceptions:

```json
[
  {
    "http": 401,
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  }
]
```

### GET `/api/mypage/:userIdx/listings`

Request:

```json
{
  "cookies": {
    "access_token": "optional"
  },
  "params": {
    "userIdx": 2
  },
  "query": {
    "type": "ALL",
    "page": 1,
    "limit": 5
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "items": [
      {
        "listingIdx": 1,
        "listingType": "USED",
        "title": "감자 키보드",
        "thumbnailUrl": "/resources/listings/1-1.png",
        "displayPrice": 10000,
        "status": "ON_SALE",
        "createdAt": "2026-07-30T13:00:00.000Z"
      }
    ],
    "page": 1,
    "limit": 5,
    "totalCount": 1,
    "totalPages": 1
  }
}
```

Exceptions:

```json
[
  {
    "http": 404,
    "code": "NOT_FOUND",
    "message": "사용자를 찾을 수 없습니다."
  }
]
```

공개 프로필의 후기 섹션은 중복 엔드포인트를 만들지 않고
`GET /api/users/:userIdx/reviews`를 그대로 사용한다.

`history`는 완료 거래뿐 아니라 사용자가 입찰한 진행 중 경매도 함께 반환한다.
`type`, `status`, `q` 조건으로 화면의 전체/판매/구매/경매 및 상태 필터를 표현한다.
