# HTTP API 상세 - 메인/검색

## 4. 메인/검색

### GET `/api/main`

Request:

```json
{
  "cookies": {
    "access_token": "optional"
  },
  "query": {
    "limit": 4
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "popularUsedListings": [
      {
        "listingIdx": 1,
        "listingType": "USED",
        "title": "감자 키보드",
        "thumbnailUrl": "/resources/listings/1-1.png",
        "category": { "categoryIdx": 2, "name": "전자기기" },
        "displayPrice": 10000,
        "status": "ON_SALE",
        "favoriteCount": 3,
        "createdAt": "2026-07-30T13:00:00.000Z"
      }
    ],
    "popularAuctionListings": [
      {
        "listingIdx": 2,
        "listingType": "AUCTION",
        "title": "경매 상품",
        "thumbnailUrl": "/resources/listings/2-1.png",
        "category": { "categoryIdx": 2, "name": "전자기기" },
        "displayPrice": 20000,
        "status": "ON_GOING",
        "favoriteCount": 5,
        "startedAt": "2026-07-30T13:00:00.000Z",
        "endsAt": "2026-07-31T13:00:00.000Z"
      }
    ],
    "recentListings": [],
    "endingSoonAuctions": [],
    "serverTime": "2026-07-30T13:30:00.000Z"
  }
}
```

Exceptions:

```json
[
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "limit 값이 올바르지 않습니다.",
    "details": { "field": "limit" }
  }
]
```

Rules:

- `limit` 기본값은 `4`이며 네 섹션에 각각 적용한다.
- 응답의 네 배열은 인기 중고, 인기 경매, 최근 등록, 마감 임박 경매 순서로 화면 섹션과 일치한다.
- 각 원소는 공통 `ListingSummary`를 사용하고 경매 원소에는 `startedAt`, `endsAt`을 포함한다.
- 남은 시간은 클라이언트가 `serverTime`과 `endsAt`으로 계산한다.

### GET `/api/categories`

Request:

```json
{
  "cookies": {},
  "query": {}
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "items": [
      {
        "categoryIdx": 1,
        "name": "의류",
        "sortOrder": 1
      },
      { "categoryIdx": 2, "name": "전자기기", "sortOrder": 2 },
      { "categoryIdx": 3, "name": "뷰티", "sortOrder": 3 },
      { "categoryIdx": 4, "name": "반려동물 용품", "sortOrder": 4 },
      { "categoryIdx": 5, "name": "도서", "sortOrder": 5 },
      { "categoryIdx": 6, "name": "악세사리", "sortOrder": 6 },
      { "categoryIdx": 7, "name": "신발", "sortOrder": 7 },
      { "categoryIdx": 8, "name": "헬스", "sortOrder": 8 }
    ]
  }
}
```

위 8개 카테고리를 초기 seed로 고정하고, 화면에는 `is_active=true`인 항목만 내려준다.

Exceptions:

```json
[]
```

### 통합 검색 보류

MVP에서는 별도 `/api/search`를 제공하지 않는다. 중고와 경매 화면은 각각
`GET /api/used`, `GET /api/auctions`의 `q`, `categoryIdx`, `sort` 조건을 사용한다.
