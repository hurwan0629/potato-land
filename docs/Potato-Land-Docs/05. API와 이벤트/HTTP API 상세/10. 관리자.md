# HTTP API 상세 - 관리자

## 11. 관리자

### GET `/api/admin/dashboard`

Request:

```json
{
  "cookies": {
    "access_token": "admin.access.jwt.value"
  },
  "query": {
    "from": "2026-07-01",
    "to": "2026-07-30",
    "interval": "DAY"
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "activeUserCount": 10,
    "totalListingCount": 20,
    "completedTransactionCount": 3,
    "totalCompletedAmount": 120000,
    "listingRegistrationCounts": [
      {
        "period": "2026-07-30",
        "count": 2
      }
    ],
    "completedTransactionCounts": [
      {
        "period": "2026-07-30",
        "count": 1
      }
    ]
  }
}
```

Exceptions:

```json
[
  {
    "http": 401,
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  },
  {
    "http": 403,
    "code": "FORBIDDEN",
    "message": "관리자 권한이 필요합니다."
  }
]
```

### GET `/api/admin/users/:userIdx`

Request:

```json
{
  "cookies": {
    "access_token": "admin.access.jwt.value"
  },
  "params": {
    "userIdx": 1
  },
  "query": {}
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "user": {
      "userIdx": 1,
      "loginId": "potato123",
      "name": "홍길동",
      "nickname": "감자왕",
      "phone": "01012345678",
      "email": "user@example.com",
      "status": "ACTIVE",
      "createdAt": "2026-07-30T13:00:00.000Z",
      "bannedAt": null,
      "bannedUntil": null,
      "deletedAt": null
    },
    "tradeSummary": {
      "sellCount": 3,
      "buyCount": 5,
      "auctionBidCount": 2
    },
    "reviewSummary": {
      "reviewCount": 10,
      "averageRating": 9.6
    },
    "recentTransactions": [],
    "recentReviews": [],
    "adminMemo": "관리자 메모"
  }
}
```

Exceptions:

```json
[
  {
    "http": 403,
    "code": "FORBIDDEN",
    "message": "관리자 권한이 필요합니다."
  },
  {
    "http": 404,
    "code": "NOT_FOUND",
    "message": "회원을 찾을 수 없습니다."
  }
]
```

`q`는 이메일, 닉네임, 이름을 한 번에 검색한다. 최근 접속 시각은 수집하지 않는다.

### GET `/api/admin/users/:userIdx/transactions`

관리자 회원 상세 화면의 거래 활동 목록이다.

Request:

```json
{
  "cookies": { "access_token": "admin.access.jwt.value" },
  "params": { "userIdx": 1 },
  "query": { "page": 1, "limit": 10 }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "items": [
      {
        "transactionIdx": 1,
        "listingIdx": 1,
        "thumbnailUrl": "/resources/listings/1-1.png",
        "title": "감자 키보드",
        "listingType": "USED",
        "tradeRole": "SELL",
        "amount": 10000,
        "status": "COMPLETED",
        "completedAt": "2026-07-30T13:10:00.000Z"
      }
    ],
    "page": 1,
    "limit": 10,
    "totalCount": 1,
    "totalPages": 1
  }
}
```

### GET `/api/admin/users/:userIdx/reviews`

관리자 회원 상세 화면의 후기 활동 목록이다. 응답 형식은
`GET /api/users/:userIdx/reviews`와 같고 삭제된 사용자 정보도 관리자용 표시명으로 보존한다.

### PATCH `/api/admin/users/:userIdx/ban`

관리자 화면의 회원 삭제 버튼에 대응한다. 실제 user row는 삭제하지 않고 `banned_at`을 저장한다.

Request:

```json
{
  "cookies": {
    "access_token": "admin.access.jwt.value"
  },
  "params": {
    "userIdx": 1
  },
  "body": {
    "reason": "운영 정책 위반"
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "userIdx": 1,
    "banned": true,
    "bannedAt": "2026-07-30T13:10:00.000Z",
    "bannedUntil": null
  }
}
```

Exceptions:

```json
[
  {
    "http": 403,
    "code": "FORBIDDEN",
    "message": "관리자 권한이 필요합니다."
  },
  {
    "http": 409,
    "code": "CONFLICT",
    "message": "이미 영구정지된 회원입니다."
  }
]
```
