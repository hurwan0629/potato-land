# HTTP API 상세 - 구현 검증 포인트

## 12. 구현 검증 포인트

- 모든 보호 API는 `access_token` 쿠키 검증 후 `deleted_at`, `banned_at`을 확인한다.
- `refresh_token`은 `/api/auth/refresh`에서만 전송되도록 path를 제한한다.
- 삭제된 게시글/경매는 일반 목록, 검색, 상세, 마이페이지, 외부 프로필에서 조회하지 않는다.
- 삭제된 게시글/경매 상세 직접 접근은 `404 NOT_FOUND`로 응답한다.
- 게시글/경매 삭제 시 해당 listing의 `favorites` 행은 삭제한다.
- 종료된 경매는 조회와 관심 등록은 허용하고, 입찰과 채팅은 차단한다.
- 비활성 사용자는 `삭제된 사용자`로 표시하고 프로필 이동을 비활성화한다.
- 비활성 사용자가 포함된 기존 채팅방은 읽기 전용으로 응답한다.
- `transactions.CANCELED`는 송금 요청 취소에만 사용한다.
- 송금 요청 취소 사유는 저장하지 않는다. 취소 시점은 `updated_at`으로 판단한다.
- 게시글/경매 상태에 `CANCELED`를 만들지 않는다.
- 후기는 `COMPLETED` 거래의 구매자/판매자만 작성할 수 있다.
- 후기 중복은 `transactionIdx + reviewerIdx` 기준으로 차단한다.
