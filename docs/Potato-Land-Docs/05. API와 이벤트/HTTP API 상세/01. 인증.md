# HTTP API 상세 - 인증

## 2. 인증

### POST `/api/auth/signup`

회원가입만 처리한다. 회원가입 성공 후 자동 로그인하지 않고, 사용자가 로그인 API를 다시 호출해야 한다.

Request:

```json
{
  "cookies": {},
  "body": {
    "name": "홍길동",
    "nickname": "감자왕",
    "loginId": "potato123",
    "password": "Password123!",
    "passwordConfirm": "Password123!",
    "phone": "01012345678",
    "email": "user@example.com",
    "termsAgreed": true,
    "privacyAgreed": true
  }
}
```

Success 201:

```json
{
  "success": true,
  "data": {
    "userIdx": 1,
    "loginId": "potato123",
    "nickname": "감자왕",
    "role": "USER",
    "profileImageUrl": null,
    "requiresLogin": true
  }
}
```

Set-Cookie: 없음

Exceptions:

```json
[
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "필수 입력값이 누락되었습니다.",
    "details": { "field": "loginId" }
  },
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "비밀번호와 비밀번호 확인이 일치하지 않습니다.",
    "details": { "field": "passwordConfirm" }
  },
  {
    "http": 409,
    "code": "CONFLICT",
    "message": "이미 사용 중인 아이디입니다.",
    "details": { "field": "loginId" }
  },
  {
    "http": 409,
    "code": "CONFLICT",
    "message": "이미 사용 중인 닉네임입니다.",
    "details": { "field": "nickname" }
  },
  {
    "http": 409,
    "code": "CONFLICT",
    "message": "이미 사용 중인 전화번호입니다.",
    "details": { "field": "phone" }
  },
  {
    "http": 409,
    "code": "CONFLICT",
    "message": "이미 사용 중인 이메일입니다.",
    "details": { "field": "email" }
  },
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "전화번호 인증이 완료되지 않았습니다.",
    "details": { "field": "phone", "purpose": "SIGNUP" }
  }
]
```

### GET `/api/auth/check-id`

Request:

```json
{
  "cookies": {},
  "query": {
    "loginId": "potato123"
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "loginId": "potato123",
    "available": true
  }
}
```

Exceptions:

```json
[
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "아이디를 입력해주세요.",
    "details": { "field": "loginId" }
  },
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "아이디 형식이 올바르지 않습니다.",
    "details": { "field": "loginId" }
  }
]
```

### POST `/api/auth/phone/send`

Request:

```json
{
  "cookies": {},
  "body": {
    "phone": "01012345678",
    "purpose": "SIGNUP"
  }
}
```

`purpose`: `SIGNUP`, `FIND_ID`, `RESET_PASSWORD`, `CHANGE_PHONE`

Success 200:

```json
{
  "success": true,
  "data": {
    "purpose": "SIGNUP",
    "phone": "01012345678",
    "expiresInSeconds": 180,
    "resendAfterSeconds": 30
  }
}
```

Exceptions:

```json
[
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "전화번호 형식이 올바르지 않습니다.",
    "details": { "field": "phone" }
  },
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "전화번호 인증 목적이 올바르지 않습니다.",
    "details": { "field": "purpose" }
  },
  {
    "http": 409,
    "code": "CONFLICT",
    "message": "이미 사용 중인 전화번호입니다.",
    "details": { "field": "phone", "purpose": "SIGNUP" }
  },
  {
    "http": 429,
    "code": "TOO_MANY_REQUESTS",
    "message": "인증번호 재발송은 30초 후 가능합니다.",
    "details": { "resendAfterSeconds": 30 }
  }
]
```

### POST `/api/auth/login`

Request:

```json
{
  "cookies": {},
  "body": {
    "loginId": "potato123",
    "password": "Password123!",
    "rememberLoginId": true
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "userIdx": 1,
    "loginId": "potato123",
    "nickname": "감자왕",
    "role": "USER",
    "profileImageUrl": "/resources/profiles/1.png"
  }
}
```

Set-Cookie:

```text
access_token=...; Max-Age=900; Path=/; HttpOnly; SameSite=Lax
refresh_token=...; Max-Age=604800; Path=/api/auth/refresh; HttpOnly; SameSite=Lax
```

Exceptions:

```json
[
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "아이디와 비밀번호를 입력해주세요.",
    "details": { "fields": ["loginId", "password"] }
  },
  {
    "http": 401,
    "code": "INVALID_CREDENTIALS",
    "message": "아이디 또는 비밀번호가 올바르지 않습니다."
  },
  {
    "http": 403,
    "code": "BANNED_USER",
    "message": "이용이 제한된 계정입니다."
  },
  {
    "http": 403,
    "code": "DELETED_USER",
    "message": "탈퇴한 계정입니다."
  }
]
```

### POST `/api/auth/logout`

Request:

```json
{
  "cookies": {
    "access_token": "optional",
    "refresh_token": "optional"
  },
  "body": {}
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "loggedOut": true
  }
}
```

Set-Cookie:

```text
access_token=; Max-Age=0; Path=/; HttpOnly; SameSite=Lax
refresh_token=; Max-Age=0; Path=/api/auth/refresh; HttpOnly; SameSite=Lax
```

Exceptions:

```json
[
  {
    "http": 200,
    "code": "NO_TOKEN",
    "message": "토큰이 없어도 로그아웃은 성공 처리합니다.",
    "details": { "loggedOut": true }
  }
]
```

  "body": {}

### POST `/api/auth/find-id`

전화번호 인증 완료 후 아이디를 팝업에 표시한다. SMS로 아이디를 보내지 않는다.

Request:

```json
{
  "cookies": {},
  "body": {
    "name": "홍길동",
    "phone": "01012345678"
  }
}
```

Success 200:

```json
{
  "success": true,
  "data": {
    "loginId": "potato123"
  }
}
```

Exceptions:

```json
[
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "이름과 전화번호 인증이 필요합니다.",
    "details": { "fields": ["name", "phone"] }
  },
  {
    "http": 400,
    "code": "VALIDATION_ERROR",
    "message": "아이디 찾기용 전화번호 인증이 아닙니다.",
    "details": { "purpose": "FIND_ID" }
  },
  {
    "http": 404,
    "code": "NOT_FOUND",
    "message": "일치하는 회원을 찾을 수 없습니다."
  }
]
```
