## 정본 규칙

- 상태와 키 이름은 `03. 도메인과 데이터`에서 한 번만 정의한다.
- HTTP 요청·응답과 Socket payload는 `04. API와 Socket`이 정본이다.
- DB transaction, Redis, 알림, Socket 부수효과는 `05. 실행 흐름`에서 설명한다.
- 그림은 `06. 다이어그램`, 화면·CSS 규칙은 `07. UI와 Figma`에서 관리한다.
- 기존 `docs/Potato-Land-Docs`는 의사결정 이력을 확인하기 위한 **과거 문서**다. 현재 구현 판단에는 이 문서 트리를 우선한다.

## 변경 원칙

코드 동작을 바꾸는 PR은 해당 API, 실행 흐름, 상태 계약, 테스트 문서를 같은 PR에서 함께 수정한다.
